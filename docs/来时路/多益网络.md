# 多益网络
- 岗位：前端开发工程师 -> 软件工程师
- base：杭州

## 一面
- 时间：8.10

### 个人情况
1. 自我介绍
2. 技术栈使用情况
3. 挑一个自己觉得最有挑战的项目

### 项目深挖
1. 项目分工情况
2. 其中的技术亮点
3. 资源状态与资源数据组织方式
4. 数据状态为什么不做与服务端的同步，而是只保存在客户端
5. 上一点是否是需求要求
6. 如果系统崩溃，编辑界面的状态丢失怎么办
7. 项目的技术卡点——数值并行计算
8. 为什么web worker就支持大规模数组计算的加速计算
9. web worker计算的内容是什么
10. ai对这个项目的参与程度，为什么不all in ai

### 技术相关
1. 有接触过tcp和udp吗
2. 视频会议使用的是udp还是tcp
3. 如果视频会议走tcp会怎样
4. udp是否会造成画面卡顿
5. 网络较差tcp和udp的表现分别是怎样
6. 是否了解递归，口头描述

### 手撕代码
- 手撕一：能否递归求和等差数列，可以的话代码实现，如果不用递归怎么实现
- 手撕二：hot100 189.轮换数组，讲下思路，为什么对k求模，评估这个方式的时空复杂度，具体手写实现，slice方法底层是怎么实现，浅拷贝还是深拷贝，对截取数组内数值修改是否影响原数组

### 情景提问
1. 是否了解C/C++
2. 对于一个不好复现和发现的bug，要怎么处理，之前是否遇到过类似情况
3. 如果希望破解滑动验证码，你有什么思路，（我回答ai替代用户行为，但避免水平移动，水平移动行为是滑动验证吗本身拦截脚本攻击的方式），ai代替用户行为的话，是否了解过相关ai操纵浏览器的框架
4. 前端自动化的框架是否接触过

### 个人情况
1. 你怎么安排自己的闲散时间
2. 每天保持多长学习时间

### 回到技术相关
1. 了解数字签名吗（我从https方面答了）
2. 内容经过公钥和私钥加密有什么区别
3. 公钥加密适用于哪些场景
4. 私钥加密适用于哪些场景
5. 如果为了保证发送的内容是自己发出来的，应该使用哪种加密方式
6. 用私钥加密保护了什么内容，避免了什么风险
