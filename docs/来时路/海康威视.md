# 海康威视
- 岗位：应用软件开发工程师
## 一志愿
- 部门：国际业务中心
- base：杭州

### 一面
- 请做一个 2–3 分钟的自我介绍，介绍项目和主要经历。
- 树形数据管理中，为什么采用 Map/哈希索引？解决了什么问题？
- 节点展开时才请求子数据会产生等待，交互上如何做友好处理？
- 编辑状态恢复涉及许多树节点，为什么采用非响应式的类实例管理状态？
- 如果直接用全局响应式状态管理所有编辑数据，会有什么问题？
- 并行计算框架中，Worker 的任务调度与复用策略是如何设计的？
- 如果并发任务数量超过 Worker 数量，任务等待队列如何处理？
- 正在执行的任务被取消时，队列与运行中的任务如何取消和补位？
- 双 Token 方案中，Hash 存储、刷新 Token 轮换/注销等机制分别解决什么安全问题？
- SSE、WebSocket、Fetch 轮询/长轮询、HTTP NDJSON 用于大模型问答时，各自优缺点是什么？
- 为什么你的场景选择 SSE？
- SSE 推送被截断、出现半个汉字或不完整 Emoji 时，前端如何处理？
- 你是否直接接收模型原始输出流？如何解码和转换？
- 从输入 URL 到首屏展示，浏览器经历哪些阶段？
- 每个阶段分别有哪些可做的性能优化？
- 页面性能问题的常规排查思路是什么？
- 用户反馈首页加载慢时，会使用哪些工具、查看哪些指标和数据？
- 你遇到过最难定位或修复的性能问题是什么？
- 多任务实时进度同步中，为什么合并为一条长连接，而不是每个计算任务各建一条连接？
- 面对 AI 对传统前端工作的影响，你如何学习和使用 AI Coding？你的使用流程是什么？
- 你使用 OpenSpec 做 Spec-Driven Development 的具体工作流是什么？
- 为什么选择 OpenSpec，而不是其他 Spec Coding 工具或二次开发框架？
