# Agent八股
## 基础概念
### 什么是Agent
#### Agent概念解释
Agent不是接一句话回一段话，而是能在多步任务中自己决定下一步做什么：先想清楚计划，再查资料、调工具，把中间结果记下来，最后汇总成答案。
```txt
Agent ≈ LLM + Planning（规划）+ Memory（记忆）+ Tools（工具）
```
- LLM：大脑，负责理解、推理、生成自然语言与结构化计划
- Planning：把模糊目标拆成可执行计划，并在执行中动态调整
- Memory：短期上下文 + 长期知识，避免「说完就忘」或重复劳动
- Tools：手脚，如搜索、数据库、代码执行、API调用等。

#### Agent与普通LLM单词调用的区别
- 普通调用：输入prompt -> 模型输出文本，没有外部环境闭环
- Agent：输出往往是「下一步动作」（例如：调用某工具、更新记忆、结束），环境返回Observation（观察结果），再进入下一轮推理，形成多轮控制循环。

#### Agent自主决策能力体现在哪
- 在动作空间中选下一步（选哪个工具、传什么参数、是否结束）
- 在信息不完整时决定先澄清还是先建设再验证。
- 在失败时决定重试、换策略或请求人工介入（视系统设计而定）
