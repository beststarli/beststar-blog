# [222.完全二叉树的节点个数](https://leetcode.cn/problems/count-complete-tree-nodes/description/)
给你一棵 **完全二叉树** 的根节点 `root` ，求出该树的节点个数。

**完全二叉树** 的定义如下：在完全二叉树中，除了最底层节点可能没填满外，其余每层节点数都达到最大值，并且最下面一层的节点都集中在该层最左边的若干位置。若最底层为第 `h` 层（从第 0 层开始），则该层包含 1~ 2<sup>h</sup> 个节点。



示例1：
![222](https://blog-1385521233.cos.ap-guangzhou.myqcloud.com/docs/algorithm/222.jpg)
- **输入**：root = [1,2,3,4,5,6]
- **输出**：6

示例2：
- **输入**：root = []
- **输出**：0

示例3：
- **输入**：root = [1]
- **输出**：1

**进阶**：遍历树来统计节点是一种时间复杂度为 O(n) 的简单解决方案。你可以设计一个更快的算法吗？

## 解题思路
### 1.BFS——违反限制
既然是统计节点个数，那么就可以想到使用层序遍历的方式，遍历每一层的节点，统计节点个数即可。

:::danger **违反限制！**
本题不允许遍历每个节点的方式来求解，否则***完全二叉树***就没有意义了。
:::

- 时间复杂度：O(n)，其中 n 是二叉树的节点数。每个节点恰好被访问一次。
- 空间复杂度：O(n)，其中 n 是二叉树的节点数。

```ts
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function countNodes(root: TreeNode | null): number {
    let count = 0
    if (root === null) {
        return count
    }
    let curr = [root]
    while (curr.length !== 0) {
        const next = []
        for (const node of curr) {
            if (node.left) {
                next.push(node.left)
            }
            if (node.right) {
                next.push(node.right)
            }
            count++
        }
        curr = next
    }
    return count
};
```

### 2.DFS——递归
利用树自身对节点递归，遇到一个节点就将数量加一。

:::danger **违反限制！**
本题不允许遍历每个节点的方式来求解，否则***完全二叉树***就没有意义了。
:::

- 时间复杂度：O(n)，其中 n 是二叉树的节点数。每个节点恰好被访问一次。
- 空间复杂度：O(n)，其中 n 是二叉树的节点数。

```ts
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function countNodes(root: TreeNode | null): number {
    if (root === null) {
        return 0
    }
    return countNodes(root.left) + countNodes(root.right) + 1
};
```

### 3.完全二叉树的性质——二分查找
对于一个**完美二叉树**来说，它的节点个数是 2<sup>h</sup> - 1，其中 h 是树的高度。根据完全二叉树的定义，除了最底层节点可能没填满外，其余每层节点数都达到最大值，并且最下面一层的节点都集中在该层最左边的若干位置。我们可以利用这个性质来计算节点个数。

从当前节点出发，一直沿着最左侧和最右侧路径向下计算深度，如果最终左侧路径和右侧路径的深度相等，说明当前子树是一个完美二叉树，可以直接计算其节点个数，即 2<sup>h</sup> - 1；否则，需要继续向下递归处理左右子树，此时节点个数为 1（当前节点）加上左子树和右子树的节点个数，即1 + countNodes(root.left) + countNodes(root.right)。

- 时间复杂度：O(log(n) * log(n))，其中 n 是二叉树的节点数。每次递归调用都需要计算深度，计算深度的时间复杂度为 O(log(n))，递归调用的次数为 O(log(n))。
- 空间复杂度：O(log(n))，其中 n 是二叉树的节点数。递归调用的栈空间最大为树的高度，即 O(log(n))。

```ts
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function countNodes(root: TreeNode | null): number {
    function dfs(node) {
        if (node === null) {
            return 0
        }
        let leftDepth = 0
        let rightDepth = 0
        let temp = node
        while (temp !== null) {
            leftDepth++
            temp = temp.left
        }

        temp = node
        while (temp !== null) {
            rightDepth++
            temp = temp.right
        }

        if (leftDepth === rightDepth) {
            return 2 ** leftDepth - 1
        } else {
            return 1 + dfs(node.left) + dfs(node.right)
        }
    }
    return dfs(root)
};
```
