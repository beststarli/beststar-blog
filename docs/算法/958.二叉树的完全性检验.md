# [958.二叉树的完全性检验](https://leetcode.cn/problems/check-completeness-of-a-binary-tree/description/)
给你一棵二叉树的根节点 `root` ，请你判断这棵树是否是一棵 **完全二叉树** 。

在一棵 **完全二叉树** 中，除了最后一层外，所有层都被完全填满，并且最后一层中的所有节点都尽可能靠左。最后一层（第 `h` 层）中可以包含 `1` 到 2<sup>h</sup> 个节点。

示例1：
![958-1](https://blog-1385521233.cos.ap-guangzhou.myqcloud.com/docs/algorithm/958-1.jpg)
- **输入**：root = [1,2,3,4,5,6]
- **输出**：true
- **解释**：最后一层前的每一层都是满的（即，节点值为 {1} 和 {2,3} 的两层），且最后一层中的所有节点（{4,5,6}）尽可能靠左。

示例2：
![113-2](https://blog-1385521233.cos.ap-guangzhou.myqcloud.com/docs/algorithm/113-2.jpg)
- **输入**：root = [1,2,3,4,5,null,7]
- **输出**：false
- **解释**：值为 7 的节点不满足条件「节点尽可能靠左」。

## 解题思路
### 1.层序遍历标记
出现空缺无非是两种情况：
- 在树中间出现空缺，下层还有节点，需要判断是左空缺还是右空缺。
- 最后一层叶子节点中间出现空缺，后面还有节点，只需要判断左空缺

那么可以采用层序遍历对二叉树进行遍历，当当前遍历节点的子节点出现空缺，就将一个全局标记`hasGap`置为true，表示后续节点不能再出现子节点，如果后续节点的子节点不为空，则返回false。这个全局标记可以处理上面的两种情况。

- 时间复杂度：O(n)，其中n是树的结点数。
- 空间复杂度：O(n)，其中n是树的结点数。

```ts
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function isCompleteTree(root: TreeNode | null): boolean {
    let curr = [root]
    let hasGap = false
    while (curr.length !== 0) {
        const next = []
        for (const node of curr) {
            if (node.left) {
                if (hasGap) {
                    return false
                }
                next.push(node.left)
            } else {
                hasGap = true
            }
            if (node.right) {
                if (hasGap) {
                    return false
                }
                next.push(node.right)
            } else {
                hasGap = true
            }
        }
        curr = next
    }
    return true
};
```

### 2.队列优化
根据队列FIFO的特性，对层序遍历代码逻辑进行优化，我们不管节点是否为空，都先填入队列中，然后从队头取出节点，如果该节点不为空则将其左右子节点加入队尾，如果该节点为空则将全局标记`hasGap`置为true，表示后续节点不能再出现子节点，如果后续节点的子节点不为空代表出现了空缺的两种情况之一，则返回false。

- 时间复杂度：O(n)，其中n是树的结点数。
- 空间复杂度：O(n)，其中n是树的结点数。

```ts
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function isCompleteTree(root: TreeNode | null): boolean {
    const queue = [root]
    let hasGap = false
    while (queue.length > 0) {
        const node = queue.shift()
        if (node === null) {
            hasGap = true
            continue
        }
        if (hasGap) {
            return false
        }
        queue.push(node.left)
        queue.push(node.right)
    }
    return true
};
```
