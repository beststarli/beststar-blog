# [67.二进制求和](https://leetcode.cn/problems/add-binary/description/?envType=study-plan-v2&envId=top-interview-150)
给你两个二进制字符串 `a` 和 `b` ，以二进制字符串的形式返回它们的和。

示例1：
- **输入**：a = "11", b = "1"
- **输出**："100"

示例2：
- **输入**：a = "1010", b = "1011"
- **输出**："10101"

## 解题思路
这道题和[415.字符串相加](./415.字符串相加)类似，整个算法几乎完全相同，只是对当前位和进位的处理要转为二进制的思路。
### 1.双指针与进位计数
还是双指针，循环条件是`p1 >= 0 || p2 >= 0 || carry === 1`，注意是或判断，确保两个字符串以及最终可能的进位都处理完。两个字符串当前位置的数字处理逻辑是只要指针还存在就将当前字符转为数字否则为0，当前位的和为`sum = numA + numB + carry`，然后将`sum % 2`作为当前位的位运算结果加入数组，更新进位为`carry = Math.floor(sum / 2)`。最后将结果数组反转并连接成字符串返回。

- 时间复杂度：O(max(m,n))，其中 m 和 n 分别是两个字符串的长度。我们需要遍历两个字符串的每一位。
- 空间复杂度：O(max(m,n))，存储结果的数组长度不会超过两个字符串中较长的那个。

```ts
function addBinary(a: string, b: string): string {
    const ans = []
    let carry = 0
    let p1 = a.length - 1
    let p2 = b.length - 1
    while (p1 >= 0 || p2 >= 0 || carry === 1) {
        const numA = (p1 >= 0) ? Number(a[p1]) : 0
        const numB = (p2 >= 0) ? Number(b[p2]) : 0
        const sum = numA + numB + carry
        ans.push(sum % 2)
        carry = Math.floor(sum / 2)
        p1--
        p2--
    }
    return ans.reverse().join('')
};
```
