# [16.最接近的三数之和](https://leetcode.cn/problems/3sum-closest/description/)   
给你一个长度为 `n` 的整数数组 `nums` 和 一个目标值 `target`。请你从 `nums` 中选出三个在 **不同下标位置** 的整数，使它们的和与 `target` 最接近。

返回这三个数的和。

假定每组输入只存在恰好一个解。

示例1：
- **输入**：nums = [-1,2,1,-4], target = 1
- **输出**：2
- **解释**：与 target 最接近的和是 2 (-1 + 2 + 1 = 2)。

示例2：
- **输入**：nums = [0,0,0], target = 1
- **输出**：0
- **解释**：与 target 最接近的和是 0（0 + 0 + 0 = 0）。

## 解题思路
### 1.双指针
参考[15.三数之和](/docs/算法/15.三数之和.md)的思路，先对数组进行升序排序，然后固定一个数字，剩下的两个数字使用双指针来寻找最接近目标值的组合。这题其实比三数之和更简单，因为不需要考虑重复的三元组，只需要找到最接近的和即可。注意使用Math.abs()来计算绝对值，判断当前的和与目标值的差是否小于之前记录的最小差，如果是，则更新最接近的和。

- 时间复杂度：O(n²)，其中 n 是数组 nums 的长度。我们需要遍历数组中的每个元素，并对剩下的元素使用双指针进行查找。
- 空间复杂度：O(1)，我们只使用了常数级别的额外空间来存储最接近的和和最小差。

```ts
function threeSumClosest(nums: number[], target: number): number {
    let ans = Infinity
    nums.sort((a, b) => a - b)
    for (let i = 0; i < nums.length - 2; i++) {
        // 跳过重复的数字
        if (i > 0 && nums[i] === nums[i - 1]) {
            continue
        }


        // 计算最小的三数之和，如果已经大于目标值，则直接返回最接近的和
        // 且不用再算了，后面的三个数字都会更大
        let sum = nums[i] + nums[i + 1] + nums[i + 2]
        if (sum > target) {
            if (sum - target < Math.abs(ans - target)) {
                ans = sum
            }
            break
        }

        // 计算最大的三数之和，如果已经小于目标值，则直接返回最接近的和
        // 当前固定的数字就不用再算了，后面的三个数字可能会更小，所以继续循环
        sum = nums[i] + nums[nums.length - 2] + nums[nums.length - 1]
        if (sum < target) {
            if (Math.abs(target - sum) < Math.abs(ans - target)) {
                ans = sum
            }
            continue
        }

        let left = i + 1
        let right = nums.length - 1
        while (left < right) {
            sum = nums[i] + nums[left] + nums[right]
            if (sum === target) {
                return target
            }
            if (Math.abs(sum - target) < Math.abs(ans - target)) {
                ans = sum
            }
            if (sum > target) {
                right--
            } else {
                left++
            }
        }
    }
    return ans
};
```
