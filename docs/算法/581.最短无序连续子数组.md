# [581.最短无序连续子数组](https://leetcode.cn/problems/shortest-unsorted-continuous-subarray/description/)
给你一个整数数组 `nums` ，你需要找出一个 **连续子数组** ，如果对这个子数组进行升序排序，那么整个数组都会变为升序排序。

请你找出符合题意的 **最短** 子数组，并输出它的长度。

示例1：
- **输入**：nums = [2,6,4,8,10,9,15]
- **输出**：5
- **解释**：你只需要对 [6, 4, 8, 10, 9] 进行升序排序，那么整个表都会变为升序排序。

示例2：
- **输入**：nums = [1,2,3,4]
- **输出**：0

示例3：
- **输入**：nums = [1]
- **输出**：0

**进阶**：你可以设计一个时间复杂度为 O(n) 的解决方案吗？

## 解题思路
### 1.双指针
建立一个对向双指针分别用于指向需要排序的首尾下标，初始化时均超出当前数组范围。end指针从-1起步，算的是要排序的子数组的右边界，start指针从nums.length起步，算的是要排序的子数组的左边界。先处理左指针，根据题目要求end指针和start指针均有两种情况：
- end指针，从左到右遍历数组，维护一个最大值
    - 如果当前值小于最大值，则说明是一段向右的下坡，那么当前值需要排序，更新end指针为当前下标；
    - 如果当前值大于等于最大值，则说明是一段超过了异常排序区间的向右的上坡，更新最大值为当前值。
- start指针，从右到左遍历数组，维护一个最小值
    - 如果当前值大于最小值，则说明是一段向左的上坡，那么当前值需要排序，更新start指针为当前下标；
    - 如果当前值小于等于最小值，则说明是一段超过了异常排序区间的向左的下坡，更新最小值为当前值。

最后返回右指针减去左指针再减一即为最短无序连续子数组的长度，注意如果这个值小于0，则返回0。

- 时间复杂度：O(n)，其中 n 是数组的长度。我们只需要遍历数组两次。
- 空间复杂度：O(1)。我们只需要常数的空间存放一些变量。

```ts
function findUnsortedSubarray(nums: number[]): number {
    const n = nums.length
    let end = -1
    let start = n

    let max = -Infinity
    for (let i = 0; i < n; i++) {
        if (nums[i] < max) {
            end = i
        } else {
            max = nums[i]
        }
    }

    let min = Infinity
    for (let i = n - 1; i >= 0; i--) {
        if (nums[i] > min) {
            start = i
        } else {
            min = nums[i]
        }
    }

    const ans = end - start + 1
    return ans < 0 ? 0 : ans
};
```

### 2.单调栈
将解法一的两个遍历过程换成单调栈实现就更好理解了，对于left指针，栈顶维护的是相当于向右下坡的起点，如果当前值小于栈顶元素，则说明当前值需要排序，更新left指针为栈顶元素的下标；如果当前值大于等于栈顶元素，则说明当前值超过了异常排序区间的上坡，入栈。right指针则是相反的思路，从右往左遍历，栈顶维护的是相当于向左上坡的起点，如果当前值大于栈顶元素，则说明当前值需要排序，更新right指针为栈顶元素的下标；如果当前值小于等于栈顶元素，则说明当前值超过了异常排序区间的下坡，入栈。

- 时间复杂度：O(n)，其中 n 是数组的长度。我们只需要遍历数组两次。
- 空间复杂度：O(n)，其中 n 是数组的长度。我们需要一个栈来存储数组的下标。

```ts
function findUnsortedSubarray(nums: number[]): number {
    const n = nums.length
    let left = n
    let right = -1
    const stack = []

    for (let i = 0; i < n; i++) {
        while (stack.length > 0 && nums[stack[stack.length - 1]] > nums[i]) {
            left = Math.min(left, stack.pop())
        }
        stack.push(i)
    }

    stack.length = 0
    for (let i = n - 1; i >= 0; i--) {
        while (stack.length > 0 && nums[stack[stack.length - 1]] < nums[i]) {
            right = Math.max(right, stack.pop())
        }
        stack.push(i)
    }

    const ans = right - left + 1
    return ans < 0 ? 0 : ans
};
```
