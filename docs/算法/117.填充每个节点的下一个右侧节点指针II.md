# [117.填充每个节点的下一个右侧节点指针II](https://leetcode.cn/problems/populating-next-right-pointers-in-each-node-ii/description/)
给定一个二叉树：
```txt
struct Node {
  int val;
  Node *left;
  Node *right;
  Node *next;
}
```
填充它的每个 next 指针，让这个指针指向其下一个右侧节点。如果找不到下一个右侧节点，则将 next 指针设置为 `NULL` 。

初始状态下，所有 next 指针都被设置为 `NULL` 。

示例1：
![117](https://blog-1385521233.cos.ap-guangzhou.myqcloud.com/docs/algorithm/117.png)
- **输入**：root = [1,2,3,4,5,null,7]
- **输出**：[1,#,2,3,#,4,5,7,#]
- **解释**：给定二叉树如图 A 所示，你的函数应该填充它的每个 next 指针，以指向其下一个右侧节点，如图 B 所示。序列化输出按层序遍历顺序（由 next 指针连接），'#' 表示每层的末尾。

示例2：
- **输入**：root = []
- **输出**：[]

**进阶**：
- 你只能使用常量级额外空间。
- 使用递归解题也符合要求，本题中递归程序占用的栈空间不算做额外的空间复杂度。

## 解题思路
本题与[116.填充每个节点的下一个右侧节点指针](/docs/算法/填充每个节点的下一个右侧节点指针)只有一个区别，就是不是完美二叉树，但是解法完全相同，无需关注层内出现的节点空缺。
### 1.BFS——层序遍历
层序遍历是最容易想到的思路，只要在遍历每一层的节点时，为前一个节点指定其next指向当前节点即可。

- 时间复杂度：O(n)，其中 n 是二叉树的节点数。每个节点恰好被访问一次。
- 空间复杂度：O(n)，其中 n 是二叉树的节点数。

```ts
/**
 * Definition for _Node.
 * class _Node {
 *     val: number
 *     left: _Node | null
 *     right: _Node | null
 *     next: _Node | null
 *     constructor(val?: number, left?: _Node, right?: _Node, next?: _Node) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *         this.next = (next===undefined ? null : next)
 *     }
 * }
 */

function connect(root: _Node | null): _Node | null {
    if (root === null) {
        return null
    }
    let curr = [root]
    while (curr.length > 0) {
        const next = []
        for (let i = 0; i < curr.length; i++) {
            if (i > 0) {
                curr[i - 1].next = curr[i]
            }
            if (curr[i].left) {
                next.push(curr[i].left)
            }
            if (curr[i].right) {
                next.push(curr[i].right)
            }
        }
        curr = next
    }
    return root
};
```

### 2.BFS——层序遍历——链表优化——进阶
既然题目都说了将二叉树每层用next指针连接，那么可以把二叉树每层都看作是一个链表，在处理当前层的时候，就可以将下层节点的next指针连接起来，等当前层处理完后，就可以直接处理下一层的链表了。这里要创建一个守卫节点dummy作为下一层链表的头节点，方便递归继续，注意每层开始时将dummy的next指针置空以处理新的一层。

- 时间复杂度：O(n)，其中 n 是二叉树的节点数。每个节点恰好被访问一次。
- 空间复杂度：O(1)，不需要额外的空间。

```ts
/**
 * Definition for _Node.
 * class _Node {
 *     val: number
 *     left: _Node | null
 *     right: _Node | null
 *     next: _Node | null
 *     constructor(val?: number, left?: _Node, right?: _Node, next?: _Node) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *         this.next = (next===undefined ? null : next)
 *     }
 * }
 */

function connect(root: _Node | null): _Node | null {
    const dummy = new _Node()
    let curr = root
    while (curr) {
        dummy.next = null
        // 下一层的链表
        let next = dummy    
        // 遍历当前层
        while (curr) {
            if (curr.left) {
                // 将下一层的相邻节点连接
                next.next = curr.left
                next = next.next
            }
            if (curr.right) {
                // 将下一层的相邻节点连接
                next.next = curr.right
                next = next.next
            }
            // 当前层链表节点前进
            curr = curr.next
        }
        // 回到下一层链表的头节点
        curr = dummy.next
    }
    return root
};
```

### 3.DFS——深度数组
构建递归函数，以深度作为标记，如果当前深度的节点是第一次访问，则将其加入结果数组中，否则将上一个当前深度的节点的next指针指向当前节点。

- 时间复杂度：O(n)，其中 n 是二叉树的节点数。每个节点恰好被访问一次。
- 空间复杂度：O(n)，其中 n 是二叉树的节点数。

```ts
/**
 * Definition for _Node.
 * class _Node {
 *     val: number
 *     left: _Node | null
 *     right: _Node | null
 *     next: _Node | null
 *     constructor(val?: number, left?: _Node, right?: _Node, next?: _Node) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *         this.next = (next===undefined ? null : next)
 *     }
 * }
 */

function connect(root: _Node | null): _Node | null {
    const prev = []
    function dfs(node, depth) {
        if (node === null) {
            return 
        }
        if (depth === prev.length) {
            prev.push(node)
        } else {
            prev[depth].next = node
            prev[depth] = node
        }
        dfs(node.left, depth + 1)
        dfs(node.right, depth + 1)
    }
    dfs(root, 0)
    return root
};
```
