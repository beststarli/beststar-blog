# [1186.删除一次得到子数组最大和](https://leetcode.cn/problems/maximum-subarray-sum-with-one-deletion/description/?envType=study-plan-v2&envId=top-interview-150)
给你一个整数数组，返回它的某个 非空 子数组（连续元素）在执行一次可选的删除操作后，所能得到的最大元素总和。换句话说，你可以从原数组中选出一个子数组，并可以决定要不要从中删除一个元素（只能删一次哦），（删除后）子数组中至少应当有一个元素，然后该子数组（剩下）的元素总和是所有子数组之中最大的。

注意，删除一个元素后，子数组 **不能为空**。

示例1：
- **输入**：arr = [1,-2,0,3]
- **输出**：4
- **解释**：我们可以选出 [1, -2, 0, 3]，然后删掉 -2，这样得到 [1, 0, 3]，和最大。

示例2：
- **输入**：arr = [1,-2,-2,3]
- **输出**：3
- **解释**：我们直接选出 [3]，这就是最大和。

示例3：
- **输入**：arr = [-1,-1,-1,-1]
- **输出**：-1
- **解释**：最后得到的子数组不能为空，所以我们不能选择 [-1] 并从中删去 -1 来得到 0。我们应该直接选择 [-1]，或者选择 [-1, -1] 再从中删去一个 -1。


## 解题思路
### 1.递归加记忆化
用一个记忆数组memo来维护当前下标i和删除状态j的最大子数组和。j=0表示已经删除过一个元素，j=1表示还没有删除过元素。递归函数dfs(i, j)表示从下标0到i的子数组中，删除状态为j时的最大子数组和。
- 当j=0时，表示已经删除过一个元素，此时只能选择当前元素arr[i]，或者选择当前元素和前一个状态的最大子数组和dfs(i-1, 0)的和。
- 当j=1时，表示还没有删除过元素，此时可以选择删除当前元素arr[i]，或者选择当前元素和前一个状态的最大子数组和dfs(i-1, 1)的和。

- 时间复杂度：O(n)，其中 n 为数组 arr 的长度。每个状态只会被计算一次。
- 空间复杂度：O(n)，其中 n 为数组 arr 的长度。递归调用栈的深度为 n，记忆数组 memo 的大小为 2n。

```ts
function maximumSum(arr: number[]): number {
    let ans = -Infinity
    const memo = Array.from({length: arr.length}, () => [null, null])
    function dfs(i, j) {
        if (i < 0) {
            return -Infinity
        }
        if (memo[i][j] !== null) {
            return memo[i][j]
        }
        if (j === 0) {
            memo[i][j] = Math.max(dfs(i - 1, 0), 0) + arr[i]
        } else {
            memo[i][j] = Math.max(dfs(i - 1, 1) + arr[i], dfs(i - 1, 0))
        }
        return memo[i][j]
    }

    for (let i = 0; i < arr.length; i++) {
        ans = Math.max(ans, dfs(i, 0), dfs(i, 1))
    }
    return ans
};
```

### 2.递推
一比一将递归翻译为递推，在创建memo数组时长度应加1方便处理边界情况，然后内部都被-Infinity填充。初始化memo[0][0] = -Infinity，memo[0][1] = -Infinity。然后从下标0开始遍历数组arr，更新memo[i + 1][0]和memo[i + 1][1]的值。最后返回ans。

- 时间复杂度：O(n)，其中 n 为数组 arr 的长度。每个状态只会被计算一次。
- 空间复杂度：O(n)，其中 n 为数组 arr 的长度。记忆数组 memo 的大小为 2n。

```ts
function maximumSum(arr: number[]): number {
    let ans = -Infinity
    const memo = Array.from({ length: arr.length + 1 }, () => [-Infinity, -Infinity])
    memo[0][0] = -Infinity;
    memo[0][1] = -Infinity;
    for (let i = 0; i < arr.length; i++) {
        memo[i + 1][0] = Math.max(memo[i][0], 0) + arr[i]
        memo[i + 1][1] = Math.max(memo[i][1] + arr[i], memo[i][0])
        ans = Math.max(ans, memo[i + 1][0], memo[i + 1][1])
    }
    return ans
};
```

### 3.空间优化
事实上，memo[i + 1][0]和memo[i + 1][1]只依赖于memo[i][0]和memo[i][1]，所以可以用两个变量dp0和dp1来代替memo数组，从而将空间复杂度优化为O(1)。遍历过程中的每一步对ans进行更新，最后返回ans。先更新dp1是因为dp1依赖于前一轮dp0的值。

- 时间复杂度：O(n)，其中 n 为数组 arr 的长度。每个状态只会被计算一次。
- 空间复杂度：O(1)，只使用了常数个额外空间。

```ts
function maximumSum(arr: number[]): number {
    let ans = -Infinity
    let dp0 = -Infinity
    let dp1 = -Infinity
    for (const num of arr) {
        dp1 = Math.max(dp1 + num, dp0)
        dp0 = Math.max(dp0, 0) + num
        ans = Math.max(ans, dp1, dp0)
    }
    return ans
};
```
