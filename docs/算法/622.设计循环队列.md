# [622.设计循环队列](https://leetcode.cn/problems/design-circular-queue/description/)
设计你的循环队列实现。 循环队列是一种线性数据结构，其操作表现基于 FIFO（先进先出）原则并且队尾被连接在队首之后以形成一个循环。它也被称为“环形缓冲器”。

循环队列的一个好处是我们可以利用这个队列之前用过的空间。在一个普通队列里，一旦一个队列满了，我们就不能插入下一个元素，即使在队列前面仍有空间。但是使用循环队列，我们能使用这些空间去存储新的值。

你的实现应该支持如下操作：
- `MyCircularQueue(k)`: 构造器，设置队列长度为 k 。
- `Front`: 从队首获取元素。如果队列为空，返回 -1 。
- `Rear`: 获取队尾元素。如果队列为空，返回 -1 。
- `enQueue(value)`: 向循环队列插入一个元素。如果成功插入则返回真。
- `deQueue()`: 从循环队列中删除一个元素。如果成功删除则返回真。
- `isEmpty()`: 检查循环队列是否为空。
- `isFull()`: 检查循环队列是否已满。

示例：
```txt
MyCircularQueue circularQueue = new MyCircularQueue(3); // 设置长度为 3
circularQueue.enQueue(1);  // 返回 true
circularQueue.enQueue(2);  // 返回 true
circularQueue.enQueue(3);  // 返回 true
circularQueue.enQueue(4);  // 返回 false，队列已满
circularQueue.Rear();  // 返回 3
circularQueue.isFull();  // 返回 true
circularQueue.deQueue();  // 返回 true
circularQueue.enQueue(4);  // 返回 true
circularQueue.Rear();  // 返回 4
```

## 解题思路
### 1.双指针
根据RingBuffer本身数据结构的特点，它需要牺牲最后一位来区分队列满和队列空的情况，所以我们需要两个指针head和tail，head指向队首元素，tail指向队尾元素的下一个位置，起始时他们都指向0，两变量始终自增，通过与 k 取模来确定实际位置。我们可以使用一个数组来存储循环队列的元素，并使用取模运算来实现循环。

各项操作的基本逻辑就是：
- isEmpty: head === tail，队列存入元素和取出元素的次数相同，此时队列为空
- isFull: tail - head为队列中元素个数，当元素个数为k时，此时队列已满
- enQueue：若队列已满返回-1，否则在nums[tail % k]存入元素，同时tail指针后移
- deQueue：若队列为空返回-1，否则head指针后移，代表队列头部元素弹出
- Front：若队列为空返回-1，否则返回nums[head % k]队头元素
- Rear：若队列为空返回-1，否则返回nums[(tail - 1) % k]队尾元素

- 时间复杂度：O(1)，每个操作都是常数时间复杂度。
- 空间复杂度：O(k)，我们需要一个长度为 k 的数组来存储循环队列的元素。

```ts
class MyCircularQueue {
    public k
    private nums
    private head
    private tail

    constructor(k: number) {
        this.k = k
        this.nums = Array(k)
        this.head = 0
        this.tail = 0
    }

    enQueue(value: number): boolean {
        if (this.isFull()) {
            return false
        }
        this.nums[this.tail % this.k] = value
        this.tail++
        return this.tail >= 0
    }

    deQueue(): boolean {
        if (this.isEmpty()) {
            return false
        }
        this.head++ 
        return this.head >= 0 
    }

    Front(): number {
        return this.isEmpty() ? -1 : this.nums[this.head % this.k]
    }

    Rear(): number {
        return this.isEmpty() ? -1 : this.nums[(this.tail - 1) % this.k]
    }

    isEmpty(): boolean {
        return this.tail === this.head
    }

    isFull(): boolean {
        return this.tail - this.head === this.k
    }
}
```
