# [257.二叉树的所有路径](https://leetcode.cn/problems/binary-tree-paths/description/)
给你一个二叉树的根节点 `root` ，按 **任意顺序** ，返回所有从根节点到叶子节点的路径。

**叶子节点** 是指没有子节点的节点。


示例1：
![257](https://blog-1385521233.cos.ap-guangzhou.myqcloud.com/docs/algorithm/257.jpg)
- **输入**：root = [1,2,3,null,5]
- **输出**：["1->2->5","1->3"]

示例2：
- **输入**：root = [1]
- **输出**：["1"]

## 解题思路
### 1.DFS
根据题干意思，到达叶子节点返回当前路径，那么可以使用DFS和前序遍历自然地处理这棵树，建立一个path数组来存储当前路径，现将当前节点的值推入path数组，如果当前节点是叶子节点即无左右子节点时将path数组转为字符串加入结果数组中。然后向下分别递归遍历左右子节点，遍历完后将当前节点从path数组中移除以恢复现场完成回溯。

- 时间复杂度：O(n)，其中 n 是二叉树的节点数。每个节点恰好被访问一次。
- 空间复杂度：O(n)，其中 n 是二叉树的节点数。

```ts
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function binaryTreePaths(root: TreeNode | null): string[] {
    const ans = []
    const path = []
    function dfs(node) {
        if (node === null) {
            return 
        }

        path.push(node.val)
        if (node.left === null && node.right === null) {
            ans.push([...path].join('->'))
        }
        dfs(node.left)
        dfs(node.right)
        path.pop()
    }
    dfs(root)
    return ans
 };
```
