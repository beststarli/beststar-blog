# [61.旋转链表](https://leetcode.cn/problems/rotate-list/description/?envType=study-plan-v2&envId=top-interview-150)

给你一个链表的头节点head，旋转链表，将链表每个节点向右移动k个位置。

示例1：
![61-1](https://blog-1385521233.cos.ap-guangzhou.myqcloud.com/docs/algorithm/61-1.jpg)
- **输入**：head = [1,2,3,4,5], k = 2
- **输出**：[4,5,1,2,3]

示例2：
![61-2](https://blog-1385521233.cos.ap-guangzhou.myqcloud.com/docs/algorithm/61-2.jpg)
- **输入**：head = [0,1,2], k = 4
- **输出**：[2,0,1]

## 解题思路
### 1.先断开再连接
由于k可能会超出整个链表的长度，当超过时旋转操作只是在重复`0 <= k <= count`的情景，所以在完成链表节点计数后应对k用count取模，注意这里如果k为0的边界情况处理，然后建立守卫节点指向原链表头部，接着遍历count - k个节点，到达断开处，通过前部链表的尾节点拿到后部链表的头部，将前部节点的next指向null，接着遍历后部链表到达尾部，将后部链表的尾节点的next指向守卫节点的next即前部链表的头节点即可，注意返回的是后部链表的头节点。

- 时间复杂度：O(n)，其中n是链表的长度。需要遍历链表两次，第一次计算链表长度，第二次找到断开点并重新连接。
- 空间复杂度：O(1)，只使用了常数级别的额外空间。

```ts
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 *     constructor(val?: number, next?: ListNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.next = (next===undefined ? null : next)
 *     }
 * }
 */

function rotateRight(head: ListNode | null, k: number): ListNode | null {
    if (head === null) {
        return null
    }
    let count = 0
    let p = head
    while (p !== null) {
        count++
        p = p.next
    }

    k %= count
    if (k === 0) {
        return head
    }
    const dummy = new ListNode(0, head)
    let p1 = dummy
    for (let i = 0; i < count - k; i++) {
        p1 = p1.next
    }

    const prevNode = p1.next
    p1.next = null
    let p2 = prevNode
    while (p2 !== null && p2.next !== null) {
        p2 = p2.next
    }
    p2.next = dummy.next
    return prevNode
};
```
