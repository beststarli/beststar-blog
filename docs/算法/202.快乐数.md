# [202.快乐数](https://leetcode.cn/problems/happy-number/description/?envType=study-plan-v2&envId=top-interview-150)
编写一个算法来判断一个数 `n` 是不是快乐数。

**「快乐数」** 定义为：
- 对于一个正整数，每一次将该数替换为它每个位置上的数字的平方和。
- 然后重复这个过程直到这个数变为 1，也可能是 **无限循环** 但始终变不到 1。
- 如果这个过程 **结果为** 1，那么这个数就是快乐数。

如果 `n` 是 **快乐数** 就返回 `true` ；不是，则返回 `false` 。

示例1：
- **输入**：n = 19
- **输出**：true
- **解释**：
    - 1<sup>2</sup> + 9<sup>2</sup> = 82
    - 8<sup>2</sup> + 2<sup>2</sup> = 68
    - 6<sup>2</sup> + 8<sup>2</sup> = 100
    - 1<sup>2</sup> + 0<sup>2</sup> + 0<sup>2</sup> = 1

示例2：
- **输入**：n = 2
- **输出**：false

## 解题思路
### 1.哈希set判环
根据题意知道，快乐数最终会计算为1，而非快乐数会陷入循环，那么陷入循环的条件是什么呢，通过手动计算可以发现就是整个过程中出现了重复的数字，那么利用哈希set去重的方法就可以判定是否进入循环，从而计算出是否为快乐数。

- 时间复杂度：O(logn)，其中 n 是输入的数字。每次计算平方和的过程中，数字的位数会减少，因此循环的次数是对数级别的。
- 空间复杂度：O(logn)，其中 n 是输入的数字。哈希set用于存储已经出现过的数字，最坏情况下可能存储所有不同的平方和，数量级为 logn。

```ts
function isHappy(n: number): boolean {
    const set = new Set()
    set.add(n)
    let temp = n
    while (true) {
        if (temp === 1) {
            return true
        }

        let sum = 0
        for (let num = temp; num > 0; num = Math.floor(num / 10)) {
            sum += (num % 10) ** 2
        }

        if (set.has(sum)) {
            return false
        } else {
            set.add(sum)
            temp = sum
        }
    }
};
```

### 2.Floyd判圈算法
Floyd判圈算法是一种用于检测链表中是否存在环的算法。在快乐数的问题中，我们可以将每个数字看作链表中的一个节点，而每个数字的下一个数字则是通过计算其各位数字的平方和得到的。如果一个数是快乐数，那么它最终会到达1，形成一个没有环的链表；如果不是快乐数，那么它会在某个时刻进入一个循环，形成一个有环的链表。因此，我们可以通过Floyd判圈算法来检测是否存在这样的循环。

- 时间复杂度：O(logn)，其中 n 是输入的数字。每次计算平方和的过程中，数字的位数会减少，因此循环的次数是对数级别的。
- 空间复杂度：O(1)，不需要额外的空间来存储已经出现过的数字，只需要使用两个指针来检测循环。

```ts
function isHappy(n: number): boolean {
    function squareSum(x) {
        let sum = 0
        for (let num = x; num > 0; num = Math.floor(num / 10)) {
            sum += (num % 10) ** 2
        }
        return sum
    }

    let slow = n
    let fast = squareSum(n)
    while (fast !== 1 && slow !== fast) {
        slow = squareSum(slow)
        fast = squareSum(squareSum(fast))
    }
    return fast === 1
};
```
