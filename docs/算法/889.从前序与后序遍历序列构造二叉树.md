# [889.从前序与后序遍历序列构造二叉树](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-postorder-traversal/description/)
给定两个整数数组，preorder 和 postorder ，其中 preorder 是一个具有 无重复 值的二叉树的前序遍历，postorder 是同一棵树的后序遍历，重构并返回二叉树。

如果存在多个答案，您可以返回其中 任何 一个。

示例1：
![889](https://blog-1385521233.cos.ap-guangzhou.myqcloud.com/docs/algorithm/889.jpg)
- **输入**：preorder = [1,2,4,5,3,6,7], postorder = [4,5,2,6,7,3,1]
- **输出**：[1,2,3,4,5,6,7]

示例2：
- **输入**：preorder = [1], postorder = [1]
- **输出**：[1]

## 解题思路
### 1.分治
从前序遍历和后序遍历无法确定一棵唯一的二叉树，我们无法像[105.根据前序和中序遍历构造二叉树](/docs/算法/根据前序和中序遍历构造二叉树)和[106.根据中序和后序遍历构造二叉树](/docs/算法/根据中序和后序遍历构造二叉树)那样，通过两个遍历序列来唯一确定一棵二叉树，因此我们需要采用其他方法。题目既然说明可以返回任意一棵二叉树，那么我们假设这棵二叉树的左右子树都存在，那么我们可以通过前序遍历的第二个节点来确定左子树的根节点，然后在后序遍历中找到这个节点的位置，这样就可以确定左子树的范围，从而递归地构造左右子树。

- 时间复杂度：O(n)，其中 n 是二叉树的节点数。每个节点恰好被访问一次。
- 空间复杂度：O(n)，其中 n 是二叉树的节点数。

```ts
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function constructFromPrePost(preorder: number[], postorder: number[]): TreeNode | null {
    const length = preorder.length
    if (length === 0) {
        return null
    }
    if (length === 1) {
        return new TreeNode(preorder[0])
    }

    const leftSize = postorder.indexOf(preorder[1]) + 1
    const pre1 = preorder.slice(1, 1 + leftSize)
    const pre2 = preorder.slice(1 + leftSize)
    const post1 = postorder.slice(0, leftSize)
    const post2 = postorder.slice(leftSize, length - 1)

    const left = constructFromPrePost(pre1, post1)
    const right = constructFromPrePost(pre2, post2)
    return new TreeNode(preorder[0], left, right)
};
```

### 2.哈希map优化检索
用哈希map对后序遍历的节点值和索引进行映射，避免每次都要用indexOf方法查找节点索引，从而优化时间复杂度。

- 时间复杂度：O(n)，其中 n 是二叉树的节点数。每个节点恰好被访问一次。
- 空间复杂度：O(n)，其中 n 是二叉树的节点数。

```ts
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function constructFromPrePost(preorder: number[], postorder: number[]): TreeNode | null {
    const length = preorder.length
    const indexMap = new Map()
    for (let i = 0; i < length; i++) {
        indexMap.set(postorder[i], i)
    }

    function dfs(preLeft, preRight, postLeft) {
        if (preLeft === preRight) {
            return null
        }
        if (preLeft + 1 === preRight) {
            return new TreeNode(preorder[preLeft])
        }

        const leftSize = indexMap.get(preorder[preLeft + 1]) - postLeft + 1
        const left = dfs(preLeft + 1, preLeft + 1 + leftSize, postLeft)
        const right = dfs(preLeft + 1 + leftSize, preRight, postLeft + leftSize)
        return new TreeNode(preorder[preLeft], left, right)
    }
    return dfs(0, length, 0)
};
```
