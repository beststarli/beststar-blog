# [450.删除二叉搜索树中的节点](https://leetcode.cn/problems/delete-node-in-a-bst/description/)
给定一个二叉搜索树的根节点 **root** 和一个值 **key**，删除二叉搜索树中的 **key** 对应的节点，并保证二叉搜索树的性质不变。返回二叉搜索树（有可能被更新）的根节点的引用。

一般来说，删除节点可分为两个步骤：
1. 首先找到需要删除的节点；
2. 如果找到了，删除它。

示例1：
![450-1](https://blog-1385521233.cos.ap-guangzhou.myqcloud.com/docs/algorithm/450-1.jpg)
- **输入**：root = [5,3,6,2,4,null,7], key = 3
- **输出**：[5,4,6,2,null,null,7]
- **解释**：
```txt
给定需要删除的节点值是 3，所以我们首先找到 3 这个节点，然后删除它。
一个正确的答案是 [5,4,6,2,null,null,7], 如下图所示。
另一个正确答案是 [5,2,6,null,4,null,7]。
```
![450-2](https://blog-1385521233.cos.ap-guangzhou.myqcloud.com/docs/algorithm/450-2.jpg)

示例2：
- **输入**：root = [5,3,6,2,4,null,7], key = 0
- **输出**：[5,3,6,2,4,null,7]
- **解释**：二叉树不包含值为 0 的节点

示例3：
- **输入**：root = [], key = 0
- **输出**：[]

**进阶**：要求算法时间复杂度为 O(h)，h 为树的高度。

## 解题思路
### 1.DFS
根据二叉搜索树的性质，如果当前节点的值大于key，则去左子树查找；如果当前节点的值小于key，则去右子树查找；如果当前节点的值等于key，就需要删除该节点，具体的操作是：
1. 如果该节点没有左子树，则直接返回右子树；
2. 如果该节点没有右子树，则直接返回左子树；
3. 如果该节点既有左子树又有右子树，则需要找到该节点的右子树的最小节点，将该最小节点的值赋给当前节点，然后删除该最小节点。

对于情况3，当到达要替换和被删除的最小节点时，这个节点一定是个叶子节点或者只有右子树的节点，所以可以直接返回它的右子树。叶子节点就返回null，也就是这棵树失去对这个节点的引用。

- 时间复杂度：O(h)，其中 h 是树的高度。最坏情况下，树是一个链表，时间复杂度为 O(n)。
- 空间复杂度：O(h)，其中 h 是树的高度。递归调用栈的空间复杂度为 O(h)。

```ts
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function deleteNode(root: TreeNode | null, key: number): TreeNode | null {
    function dfs(node) {
        if (node === null) {
            return null
        }
        if (node.val > key) {
            node.left = deleteNode(node.left, key)
        } else if (node.val < key) {
            node.right = deleteNode(node.right, key)
        } else {
            if (node.left === null) {
                return node.right
            }
            if (node.right === null) {
                return node.left
            }

            let minNode = node.right
            while (minNode.left) {
                minNode = minNode.left
            }
            node.val = minNode.val
            node.right = deleteNode(node.right, minNode.val)
        }
        return node
    }
    return dfs(root)
};
```
