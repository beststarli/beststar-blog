# [451.根据字符出现频率排序](https://leetcode.cn/problems/sort-characters-by-frequency/description/)
给定一个字符串 `s` ，根据字符出现的 **频率** 对其进行 **降序排序** 。一个字符出现的 **频率** 是它出现在字符串中的次数。

返回 *已排序的字符串* 。如果有多个答案，返回其中任何一个。

示例1：
- **输入**：s = "tree"
- **输出**："eert"
- **解释**：
```txt
'e'出现两次，'r'和't'都只出现一次。
因此'e'必须出现在'r'和't'之前。此外，"eetr"也是一个有效的答案。
```

示例2：
- **输入**：s = "cccaaa"
- **输出**："cccaaa"
- **解释**：
```txt
'c'和'a'都出现三次。此外，"aaaccc"也是有效的答案。
注意"cacaca"是不正确的，因为相同的字母必须放在一起。
```

示例3：
- **输入**：s = "Aabb"
- **输出**："bbAa"
- **解释**：
```txt
此外，"bbaA"也是一个有效的答案，但"Aabb"是不正确的。
注意'A'和'a'被认为是两种不同的字符。
```

## 解题思路
### 1.桶排序
与[347.前K个高频元素](/docs/算法/前K个高频元素)与[692.前K个高频单词](/docs/算法/前K个高频单词)类似，都是先去用哈希map统计元素频率，在建立一个长度为最大出现频率加1的桶，这样bucket[i]就代表出现次数为i的元素列表。最后倒着遍历这个桶，将出现次数多的元素放在前面，直到遍历完整个桶。注意在处理某个桶时对其中字符按字典序排序。

- 时间复杂度：O(nlogn)，其中 n 是字符串的长度。我们需要遍历字符串来统计频率，然后对每个桶内的字符进行排序。
- 空间复杂度：O(n)，我们需要存储每个字符的出现次数以及桶的内容。

```ts
function frequencySort(s: string): string {
    const count = new Map()
    s.split('').forEach(char => {
        count.set(char, (count.get(char) ?? 0) + 1)
    })

    const maxCount = Math.max(...count.values())
    const bucket = Array.from({ length: maxCount + 1 }, () => [])
    for (const [char, times] of count) {
        bucket[times].push(char)
    }

    let ans = ''
    for (let i = maxCount; i >= 0; i--) {
        bucket[i].sort()
        if (bucket[i].length > 0) {
            for (const char of bucket[i]) {
                ans += char.repeat(i)
            }
        }
    }
    return ans
};
```
