# [18.四数之和](https://leetcode.cn/problems/4sum/description/)   
给你一个由 `n` 个整数组成的数组 `nums` ，和一个目标值 `target` 。请你找出并返回满足下述全部条件且不重复的四元组 `[nums[a], nums[b], nums[c], nums[d]]` （若两个四元组元素一一对应，则认为两个四元组重复）：
- `0 <= a, b, c, d < n`
- `a`、`b`、`c` 和 `d` 互不相同
- `nums[a] + nums[b] + nums[c] + nums[d] == target`

你可以按 **任意顺序** 返回答案 。

示例1：
- **输入**：nums = [1,0,-1,0,-2,2], target = 0
- **输出**：[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]

示例2：
- **输入**：nums = [2,2,2,2,2], target = 8
- **输出**：[[2,2,2,2]]

## 解题思路
### 1.双指针
依然是基于[15.三数之和](/docs/算法/15.三数之和.md)的思路，先对数组进行升序排序，不过要先固定两个数字，事实上就是用两层循环实现，剩下的两个数字使用双指针来寻找满足条件的组合。相当于是计算了两层“三数之和”，注意本题需要去重。

- 时间复杂度：O(n³)，其中 n 是数组 nums 的长度。我们需要遍历数组中的每个元素，并对剩下的元素使用双指针进行查找。
- 空间复杂度：O(1)，我们只使用了常数级别的额外空间来存储结果。


```ts
function fourSum(nums: number[], target: number): number[][] {
    nums.sort((a, b) => a - b)
    const ans = []
    // 固定第一个数字
    for (let i = 0; i < nums.length - 3; i++) {
        // 跳过重复的数字
        if (i > 0 && nums[i] === nums[i - 1]) {
            continue
        }

        // 最小的四数之和，如果已经大于目标值，则后面只会更大，退出循环
        if (nums[i] + nums[i + 1] + nums[i + 2] + nums[i + 3] > target) {
            break
        }

        // 最大的四数之和，如果已经小于目标值，则后面可能取得目标值，继续循环推进固定数字
        if (nums[i] + nums[nums.length - 3] + nums[nums.length - 2] + nums[nums.length - 1] < target) {
            continue
        }

        // 固定第二个数字，起点是i+1，终点是nums.length-2
        for (let j = i + 1; j < nums.length - 2; j++) {
            // 跳过重复的数字
            if (j > i + 1 && nums[j] === nums[j - 1]) {
                continue
            }

            // 最小的四数之和，如果已经大于目标值，则后面只会更大，退出循环
            if (nums[i] + nums[j] + nums[j + 1] + nums[j + 2] > target) {
                break
            }

            // 最大的四数之和，如果已经小于目标值，则后面可能取得目标值，继续循环推进固定数字
            if (nums[i] + nums[j] + nums[nums.length - 2] + nums[nums.length - 1] < target) {
                continue
            }

            // 双指针
            let left = j + 1
            let right = nums.length - 1
            while (left < right) {
                const sum = nums[i] + nums[j] + nums[left] + nums[right]
                if (sum > target) {
                    right--
                } else if (sum < target) {
                    left++
                } else {
                    ans.push([nums[i], nums[j], nums[left], nums[right]])
                    // 跳过重复的数字
                    while (left < right && nums[left] === nums[left + 1]) {
                        left++
                    }
                    // 跳过重复的数字
                    while (left < right && nums[right] === nums[right - 1]) {
                        right--
                    }
                    left++
                    right--
                }
            }
        }
    }
    return ans
};
```
