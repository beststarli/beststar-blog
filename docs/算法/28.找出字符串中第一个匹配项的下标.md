# [28.找出字符串中第一个匹配项的下标](https://leetcode.cn/problems/find-the-index-of-the-first-occurrence-in-a-string/description/)
给你两个字符串 `haystack` 和 `needle` ，请你在 `haystack` 字符串中找出 `needle` 字符串的第一个匹配项的下标（下标从 0 开始）。如果 `needle` 不是 `haystack` 的一部分，则返回  `-1` 。

示例1：
- **输入**：haystack = "sadbutsad", needle = "sad"
- **输出**：0
- **解释**："sad" 在下标 0 和 6 处匹配。第一个匹配项的下标是 0 ，所以返回 0 。

示例2：
- **输入**：haystack = "leetcode", needle = "leeto"
- **输出**：-1
- **解释**："leeto" 没有在 "leetcode" 中出现，所以返回 -1 。

## 解题思路
这是一道典型的KMP应用题。
### 1.BF算法——双指针暴力
用双指针来遍历 haystack 和 needle，指针1指向haystack，指针2指向needle。首先移动指针1直到haystack[pointer1]与needle[pointer2]相等，然后记录下当前的起始位置start，并继续移动两个指针，直到遇到不相等的字符或者指针2到达needle的末尾。如果指针2到达needle的末尾，则说明找到了匹配项，返回start。如果不相等，则将指针1回退到start + 1的位置，指针2重置为0，继续查找。

- 时间复杂度：O(n * m)，其中 n 是 haystack 的长度，m 是 needle 的长度。我们需要遍历 haystack 中的每个字符，并在每个位置尝试匹配 needle。
- 空间复杂度：O(1)，我们只需要常数级别的额外空间来存储指针和索引。

```ts
function strStr(haystack: string, needle: string): number {
    let pointer1 = 0
    let pointer2 = 0
    while (pointer1 < haystack.length && pointer2 < needle.length) {
        while (haystack[pointer1] !== needle[pointer2]) {
            pointer1++
            if (pointer1 >= haystack.length) {
                return -1
            }
        }
        const start = pointer1
        while (pointer1 < haystack.length && pointer2 < needle.length && haystack[pointer1] === needle[pointer2]) {
            pointer1++
            pointer2++
        }
        if (pointer2 >= needle.length) {
            return start
        }
        pointer1 = start + 1
        pointer2 = 0
    }
    return -1
};
```

### 2.优化双指针写法
pre指针记录当前haystack中遍历的起始位置，after指针记录当前needle中遍历的位置。首先移动pre指针直到haystack[pre + after]与needle[after]相等，然后继续移动两个指针，直到遇到不相等的字符或者after到达needle的末尾。如果after到达needle的末尾，则说明找到了匹配项，返回pre。如果不相等，则将pre指针加1，after指针重置为0，继续查找。

- 时间复杂度：O(n * m)，其中 n 是 haystack 的长度，m 是 needle 的长度。我们需要遍历 haystack 中的每个字符，并在每个位置尝试匹配 needle。
- 空间复杂度：O(1)，我们只需要常数级别的额外空间来存储指针和索引。

```ts
function strStr(haystack: string, needle: string): number {
    let pre = 0
    let after = 0
    while (after < needle.length && pre < haystack.length) {
        if (haystack[pre + after] === needle[after]) {
            after++
        } else {
            pre++
            after = 0
        }
    }
    return after === needle.length ? pre : -1
};
```

### 4.KMP算法


```ts
function strStr(haystack: string, needle: string): number {
    const m = haystack.length
    const n = needle.length
    const next = Array(n).fill(0)

    let j = 0
    // 构建前缀数组next
    for (let i = 1; i < n; i++) {
        // 不匹配时回退
        while (j > 0 && needle[i] !== needle[j]) {
            j = next[j - 1]
        }
        // 匹配则j前进
        if (needle[i] === needle[j]) {
            j++
        }
        next[i] = j
    }

    j = 0
    // 用next数组匹配字符串
    for (let i = 0; i < m; i++) {
        while (j > 0 && haystack[i] !== needle[j]) {
            j = next[j - 1]
        }
        if (haystack[i] === needle[j]) {
            j++
        }
        if (j === n) {
            return i - n + 1
        }
    }
    return -1
};
```
