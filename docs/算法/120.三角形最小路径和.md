# [120.三角形最小路径和](https://leetcode.cn/problems/triangle/description/)
给定一个三角形 `triangle` ，找出自顶向下的最小路径和。

每一步只能移动到下一行中相邻的结点上。相邻的结点 在这里指的是 **下标** 与 **上一层结点下标** 相同或者等于 **上一层结点下标 + 1** 的两个结点。也就是说，如果正位于当前行的下标 `i` ，那么下一步可以移动到下一行的下标 `i` 或 `i + 1` 。



示例1：
- **输入**：triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
- **输出**：11
- **解释**：如下面简图所示：
```
   2
  3 4
 6 5 7
4 1 8 3
```
自顶向下的最小路径和为 11（即，2 + 3 + 5 + 1 = 11）。


示例2：
- **输入**：triangle = [[-10]]
- **输出**：-10

## 解题思路
### 1.递归加记忆化
将三角形每层都左对齐，发现其实有点类似杨辉三角的思路，只不过杨辉三角是用上一层算当前层，而本题递归是一个dfs，从顶部根节点开始往下一层一层去递，直到最后一层。递归出口是当递归到最后一层时，返回当前节点的值。每次递归时，计算当前节点的值加上下一层的左右子节点的最小值。

- 时间复杂度：O(n^2)，其中 n 是三角形的行数。每个位置只会被访问一次。
- 空间复杂度：O(n^2)，其中 n 是三角形的行数。递归调用栈的深度为 n，记忆化数组的大小为 n^2。

```ts
function minimumTotal(triangle: number[][]): number {
    const memo = Array.from({ length: triangle.length }, () => Array(triangle.length).fill(Infinity))

    function dfs(i, j) {
        if (i === triangle.length - 1) {
            return triangle[i][j]
        } 
        if (memo[i][j] !== Infinity) {
            return memo[i][j]
        }
        memo[i][j] = Math.min(dfs(i + 1, j), dfs(i + 1, j + 1)) + triangle[i][j]
        return memo[i][j]
    }
    return dfs(0, 0)
};
```

### 2.动态规划——递推
一比一翻译成递推，依然是把递归的思路反过来从底下往上算到顶层。建立一个二维数组 `memo`，`memo[i][j]` 表示从第 `i` 层第 `j` 个节点到最后一层的最小路径和。初始化 `memo` 的最后一层为三角形的最后一层，因为这层的最小路径和就是它本身的值，然后从倒数第二层开始往上计算每个节点的最小路径和。

- 时间复杂度：O(n^2)，其中 n 是三角形的行数。每个位置只会被访问一次。
- 空间复杂度：O(n^2)，其中 n 是三角形的行数。需要一个二维数组来存储每个位置的最小路径和。

```ts
function minimumTotal(triangle: number[][]): number {
    const memo = Array.from({ length: triangle.length }, () => Array(triangle.length).fill(Infinity))
    memo[triangle.length - 1] = triangle[triangle.length - 1]

    for (let i = triangle.length - 2; i >= 0; i--) {
        for (let j = 0; j <= i; j++) {
            memo[i][j] = Math.min(memo[i + 1][j], memo[i + 1][j + 1]) + triangle[i][j]
        }
    }
    return memo[0][0]
};
```

### 3.空间优化
结合前面两种写法的思路，既然我们是从最顶部一个节点出发向下找路径的，那这里就是最终返回的入口，又知道一层某个节点的最小路径只与它下一层的正下方和右下方的节点有关，另外最底层节点的最小路径就是它本身的值，所以我们可以直接在原数组上进行修改，直接去累加对他有影响的两个节点中的最小值即可，最后返回顶部节点的值就是答案。

- 时间复杂度：O(n^2)，其中 n 是三角形的行数。每个位置只会被访问一次。
- 空间复杂度：O(1)。不需要额外的空间。

```ts
function minimumTotal(triangle: number[][]): number {
    for (let i = triangle.length - 2; i >= 0; i--) {
        for (let j = 0; j <= i; j++) {
            triangle[i][j] += Math.min(triangle[i + 1][j], triangle[i + 1][j + 1])
        }
    }
    return triangle[0][0]
};
```
