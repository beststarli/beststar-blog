# [454.四数相加II](https://leetcode.cn/problems/4sum-ii/description/)   
给你四个整数数组 `nums1`、`nums2`、`nums3` 和 `nums4` ，数组长度都是 `n` ，请你计算有多少个元组 `(i, j, k, l)` 能满足：
- `0 <= i, j, k, l < n`
- `nums1[i] + nums2[j] + nums3[k] + nums4[l] == 0`

示例1：
- **输入**：nums1 = [1,2], nums2 = [-2,-1], nums3 = [-1,2], nums4 = [0,2]
- **输出**：2
- **解释**：
```txt
两个元组如下：
1. (0, 0, 0, 1) -> nums1[0] + nums2[0] + nums3[0] + nums4[1] = 1 + (-2) + (-1) + 2 = 0
2. (1, 1, 0, 0) -> nums1[1] + nums2[1] + nums3[0] + nums4[0] = 2 + (-1) + (-1) + 0 = 0
```

示例2：
- **输入**：nums1 = [0], nums2 = [0], nums3 = [0], nums4 = [0]
- **输出**：1

## 解题思路
### 1.求和哈希map
可以把四数之和看作是两两相加的两数之和，也就是(num1 + num2) + (num3 + num4) = 0，等价于(num1 + num2) = -(num3 + num4)。所以我们可以先遍历前两个数组，计算所有可能的两数之和，并将其存入哈希表中，键为两数之和，值为该和出现的次数。然后再遍历后两个数组，计算它们的两数之和，并检查哈希表中是否存在与其相反数的键，如果存在，则将该键对应的值累加到结果中。

- 时间复杂度：O(n^2)，其中 n 是数组的长度。我们需要遍历前两个数组和后两个数组各一次。
- 空间复杂度：O(n^2)，因为我们需要存储前两个数组的所有可能的两数之和及其出现次数。

```ts
function fourSumCount(nums1: number[], nums2: number[], nums3: number[], nums4: number[]): number {
    let ans = 0
    const count = new Map()
    for (const num1 of nums1) {
        for (const num2 of nums2) {
            count.set(num1 + num2, (count.get(num1 + num2) ?? 0) + 1)
        }
    }
    for (const num3 of nums3) {
        for (const num4 of nums4) {
            ans += count.get(-(num3 + num4)) ?? 0
        }
    }
    return ans
};
```
