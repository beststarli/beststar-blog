# [LCR 143.子结构判断](https://leetcode.cn/problems/shu-de-zi-jie-gou-lcof/description/)
给定两棵二叉树 `tree1` 和 `tree2`，判断 `tree2` 是否以 `tree1` 的某个节点为根的子树具有 相同的结构和节点值 。

注意，空树 不会是以 `tree1` 的某个节点为根的子树具有 相同的结构和节点值 。


示例1：
![lcr143-1](https://blog-1385521233.cos.ap-guangzhou.myqcloud.com/docs/algorithm/lcr143-1.png)
- **输入**：tree1 = [1,7,5], tree2 = [6,1]
- **输出**：false
- **解释**：tree2 与 tree1 的一个子树没有相同的结构和节点值。

示例2：
![lcr143-2](https://blog-1385521233.cos.ap-guangzhou.myqcloud.com/docs/algorithm/lcr143-2.png)
- **输入**：tree1 = [3,6,7,1,8], tree2 = [6,1]
- **输出**：true
- **解释**：tree2 与 tree1 的一个子树拥有相同的结构和节点值。即 6 - > 1。

## 解题思路
### 1.DFS

```ts
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function contains(node1, node2) {
    if (node2 === null) {
        return true
    }
    if (node1 === null) {
        return false
    }
    if (node1.val !== node2.val) {
        return false
    }

    const left = contains(node1.left, node2.left)
    const right = contains(node1.right, node2.right)

    return left && right
}

function isSubStructure(A: TreeNode | null, B: TreeNode | null): boolean {
    if (A === null || B === null) {
        return false
    }
    return contains(A, B) || isSubStructure(A.left, B) || isSubStructure(A.right, B)
};
```
