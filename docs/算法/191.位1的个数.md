# [191.位1的个数](https://leetcode.cn/problems/number-of-1-bits/description/?envType=study-plan-v2&envId=top-interview-150)
给定一个正整数 n，编写一个函数，获取一个正整数的二进制形式并返回其二进制表达式中 **设置位** 的个数（也被称为[汉明重量](https://baike.baidu.com/item/%E6%B1%89%E6%98%8E%E9%87%8D%E9%87%8F)）。

:::info **set bit**
**set bit** 指在某数的二进制表示中值为 **1** 的二进制位。
:::

示例1：
- **输入**：n = 11
- **输出**：3
- **解释**：输入的二进制串 1011 中，共有 3 个设置位。

示例2：
- **输入**：n = 128
- **输出**：1
- **解释**：输入的二进制串 10000000 中，共有 1 个设置位。

示例3：
- **输入**：n = 2147483645
- **输出**：30
- **解释**：输入的二进制串 1111111111111111111111111111101 中，共有 30 个设置位。

**进阶**：如果多次调用这个函数，你将如何优化你的算法？

## 解题思路
### 1.右移位
通过将数字与1做与运算，判断当前位是否为1，然后将数字右移一位，直到数字为0。之所以用1做与运算而不是用2做模运算，是因为后者在处理负数时会出现求模结果为负数的情况，加入ans会导致出错，不过本题有说明n >= 1，事实上也可以用2做模运算，结果是一样的。

- 时间复杂度：O(logn)，其中 n 为输入的整数。每次右移一位，最多需要 logn 次操作。
- 空间复杂度：O(1)。

```ts
function hammingWeight(n: number): number {
    let ans = 0
    while (n !== 0) {
        ans += n & 1
        n >>>= 1
    }
    return ans
};
```

### 2.模运算
- 时间复杂度：O(logn)，其中 n 为输入的整数。每次除以2，最多需要 logn 次操作。
- 空间复杂度：O(1)。

```ts
function hammingWeight(n: number): number {
    let ans = 0
    while (n !== 0) {
        ans += n % 2
        n = Math.floor(n / 2)   // ← 不能写成 n /= 2
    }
    return ans
};
```
