# [973.最接近原点的K个点](https://leetcode.cn/problems/k-closest-points-to-origin/description/)
给定一个数组 `points` ，其中 points[i] = [x<sub>i</sub>, y<sub>i</sub>] 表示 **X-Y** 平面上的一个点，并且是一个整数 `k` ，返回离原点 `(0,0)` 最近的 `k` 个点。

这里，平面上两点之间的距离是 **欧几里德距离**（ √(x1 - x2)<sup>2</sup> + (y1 - y2)<sup>2</sup> ）。

你可以按 **任何顺序** 返回答案。除了点坐标的顺序之外，答案 确保 是 **唯一** 的。

示例1：
![973](https://blog-1385521233.cos.ap-guangzhou.myqcloud.com/docs/algorithm/973.jpg)
- **输入**：points = [[1,3],[-2,2]], k = 1
- **输出**：[[-2,2]]
- **解释**：
```txt
(1, 3) 和原点之间的距离为 sqrt(10)，
(-2, 2) 和原点之间的距离为 sqrt(8)，
由于 sqrt(8) < sqrt(10)，(-2, 2) 离原点更近。
我们只需要距离原点最近的 K = 1 个点，所以答案就是 [[-2,2]]。
```

示例2：
- **输入**：points = [[3,3],[5,-1],[-2,4]], k = 2
- **输出**：[[3,3],[-2,4]]

## 解题思路
### 1.桶排序
与[347.前K个高频元素](/docs/算法/前K个高频元素)、[692.前K个高频单词](/docs/算法/前K个高频单词)、[451.根据字符出现频率排序](/docs/算法/根据字符出现频率排序)类似，用每个point与原点距离的平方和作为键，同平方和的放在同一个数组中作为值，存入哈希map中。然后再用桶排序的方式，遍历所有的平方和，直到找到k个点。

:::danger **超时！**
这个写法没法通过全部测试用例
:::

- 时间复杂度：O(n^2)，其中 n 是数组的长度。我们需要遍历所有点来计算平方和，并将其存入哈希表中，然后再遍历平方和的桶。
- 空间复杂度：O(n^2)，因为我们需要存储所有点的平方和及其对应的点。

```ts
function kClosest(points: number[][], k: number): number[][] {
    let squareMap = new Map()
    for (const point of points) {
        const squareSum = point[0] ** 2 + point[1] ** 2
        // squareMap.set(squareSum, (squareMap.get(squareSum) ?? []).push(point))
        if (!squareMap.has(squareSum)) {
            squareMap.set(squareSum, [])
        }
        squareMap.get(squareSum).push(point)
    }
    const maxSquare = Math.max(...squareMap.keys())
    const bucket = Array.from({ length: maxSquare + 1 }, () => [])
    for (const [sum, pointsArr] of squareMap) {
        bucket[sum] = pointsArr
    }

    let ans = []
    for (const arr of bucket) {
        if (arr.length > 0) {
            for (const point of arr) {
                ans.push(point)
                if (ans.length === k) {
                    return ans
                }
            }
        }
    }
    return ans
};
```

### 2.数组排序规则
根据数组sort()方法的规则，在内部比较点a和点b的平方和，返回a平方和与b平方和的差值，升序排列。通过slice(0, k)取前k个点。

- 时间复杂度：O(nlogn)，其中 n 是数组的长度。我们需要对所有点进行排序。
- 空间复杂度：O(logn)，这是排序所需的空间。

```ts
function kClosest(points: number[][], k: number): number[][] {
    return points.sort((a, b) => {
        const aSquare = a[0] ** 2 + a[1] ** 2
        const bSquare = b[0] ** 2 + b[1] ** 2
        return aSquare - bSquare
    }).slice(0, k)
};
```

### 3.快速选择
借助守卫pivot对数组进行快速划分，快速选择内部当返回的下标不为k - 1，即前k个点没排序好时，继续递归调用快速选择来划分，直到前k个点排序好。然后通过数组的slice(0, k)取前k个点即可。

:::success **最优解**
这是时间、空间复杂度最优的解法。
:::

- 时间复杂度：O(n)，其中 n 是数组的长度。快速选择的平均时间复杂度为O(n)，最坏情况下为O(n^2)。
- 空间复杂度：O(logn)，这是递归调用所需的空间。

```ts
function distance(point: [number, number]) {
    return point[0] ** 2 + point[1] ** 2
}

function quickSelect(points, left, right, k) {
    const index = Math.floor(Math.random() * (right - left + 1)) + left
    const pivot = distance(points[index])
    let i = left + 1
    let j = right
        ;[points[left], points[index]] = [points[index], points[left]]
    while (true) {
        while (i <= j && distance(points[i]) < pivot) {
            i++
        }
        while (i <= j && distance(points[j]) > pivot) {
            j--
        }
        if (i >= j) {
            break
        }
        [points[i], points[j]] = [points[j], points[i]]
        i++
        j--
    }
    ;[points[left], points[j]] = [points[j], points[left]]
    if (j === k - 1) {
        return 
    }
    if (j > k - 1) {
        quickSelect(points, left, j - 1, k)
    } else {
        quickSelect(points, j + 1, right, k)
    }
}

function kClosest(points: number[][], k: number): number[][] {
    const index = quickSelect(points, 0, points.length - 1, k)
    return points.slice(0, k)
};
```
