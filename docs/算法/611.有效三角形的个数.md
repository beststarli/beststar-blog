# [611.有效三角形的个数](https://leetcode.cn/problems/valid-triangle-number/description/)
给定一个包含非负整数的数组 `nums` ，返回其中可以组成三角形三条边的三元组个数。

示例1：
- **输入**：nums = [2,2,3,4]
- **输出**：3
- **解释**：
```txt
有效的组合是: 
2,3,4 (使用第一个 2)
2,3,4 (使用第二个 2)
2,2,3
```

## 解题思路
### 1.双指针
对数组进行升序排序后，根据三角形的性质，一个合理的三角形要求任意两边之和大于第三边，那么可以倒着遍历数组，固定最长边，夹逼双指针依次扫过可能的另外两边，双指针有两种情况：
- 出现两边之和大于第三边，那么此时如果固定右指针，左指针向右移动得到的边都符合条件，所以结果累加right-left，右指针向左移动缩小两边和的最大值。
- 两边之和小于第三边，左指针向右移动增大两边和的最小值。

- 时间复杂度：O(n²)，其中 n 是数组的长度。我们需要对数组进行排序，然后使用双指针遍历数组。
- 空间复杂度：O(1)，我们只使用了常数级别的额外空间来存储结果。

```js
function triangleNumber(nums: number[]): number {
    let ans = 0
    nums.sort((a, b) => a - b)
    const length = nums.length
    for (let i = length - 1; i >= 2; i--) {
        let left = 0
        let right = i - 1
        while (left < right) {
            if (nums[left] + nums[right] > nums[i]) {
                ans += right - left
                right--
            } else {
                left++
            }
        }
    }
    return ans
};
```
