# [6.Z字形变换](https://leetcode.cn/problems/zigzag-conversion/description/?envType=study-plan-v2&envId=top-interview-150)
将一个给定字符串 `s` 根据给定的行数 `numRows` ，以从上往下、从左到右进行 Z 字形排列。

比如输入字符串为 `"PAYPALISHIRING"` 行数为 `3` 时，排列如下：
```txt
P   A   H   N
A P L S I I G
Y   I   R
```
之后，你的输出需要从左往右逐行读取，产生出一个新的字符串，比如：`"PAHNAPLSIIGYIR"`。

请你实现这个将字符串进行指定行数变换的函数：
```txt
string convert(string s, int numRows);
```

示例1：
- **输入**：s = "PAYPALISHIRING", numRows = 3
- **输出**："PAHNAPLSIIGYIR"

示例2：
- **输入**：s = "PAYPALISHIRING", numRows = 4
- **输出**："PINALSIGYAHRPI"
- **解释**：
```txt
P     I    N
A   L S  I G
Y A   H R
P     I
```

示例3：
- **输入**：s = "A", numRows = 1
- **输出**："A"

## 解题思路
### 1.计数反转
所谓的Z字型，其实就是在每一行的字符之间，存在一个规律性的间隔。我们可以通过计数器来模拟这个规律，而不是真的在每一行中都去塞入空间隔，初始化一个字符串数组，长度为numRows，模拟二维数组，用一个变量i表示当前处理的行号，还有一个标志flag初始为-1，以要处理的字符串为遍历基础，对当前遍历行的字符串接上当前字符，之后判断当前行号是否为0或numRows-1，如果是则反转flag，然后i通过加flag来实现在行之间的上下移动，当i到达最顶行或最底行时，就改变flag的符号即完成变向，这个过程有点像折返跑。

- 时间复杂度：O(n)，其中 n 是字符串 s 的长度。我们只需要遍历一次字符串即可。
- 空间复杂度：O(n)，我们需要一个长度为 numRows 的字符串数组。

```ts
function convert(s: string, numRows: number): string {
    if (numRows < 2) {
        return s
    }
    const rows = Array(numRows).fill('')
    let i = 0
    let flag = -1
    for (const char of s) {
        rows[i] += char
        if (i === 0 || i === numRows - 1) {
            flag = -flag
        }
        i += flag
    }
    return rows.join('')
};
```
