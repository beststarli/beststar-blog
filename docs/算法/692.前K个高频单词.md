# [692.前K个高频单词](https://leetcode.cn/problems/top-k-frequent-words/description/)   
给定一个单词列表 `words` 和一个整数 `k` ，返回前 `k` 个出现次数最多的单词。

返回的答案应该按单词出现频率由高到低排序。如果不同的单词有相同出现频率， **按字典顺序** 排序。

示例1：
- **输入**：words = ["i", "love", "leetcode", "i", "love", "coding"], k = 2
- **输出**：["i", "love"]
- **解释**：
```txt
"i" 和 "love" 为出现次数最多的两个单词，均为2次。
注意，按字母顺序 "i" 在 "love" 之前。
```

示例2：
- **输入**：["the", "day", "is", "sunny", "the", "the", "the", "sunny", "is", "is"], k = 4
- **输出**：["the", "is", "sunny", "day"]
- **解释**：
```txt
"the", "is", "sunny" 和 "day" 是出现次数最多的四个单词，
出现次数依次为 4, 3, 2 和 1 次。
```

**进阶**：尝试以 O(n log k) 时间复杂度和 O(n) 空间复杂度解决。

## 解题思路
### 1.桶排序——进阶
这题与[347.前K个高频元素](/docs/算法/前K个高频元素)类似，都是求前K个高频元素。不同的是，这题需要对出现次数相同的单词按字典顺序排序。且对结果长度严格检查。

还是先用一个哈希map来统计每个单词的出现频率，再建立一个长度为最大出现频率加1的桶，这样bucket[i]就代表出现次数为i的单词列表。最后倒着遍历这个桶，直到答案数组的长度达到k停止。

- 时间复杂度：O(nlogn)，其中 n 是单词列表的长度。我们需要遍历单词列表来统计频率，然后对每个桶内的单词进行排序。
- 空间复杂度：O(n)，我们需要存储每个单词的出现次数以及桶的内容。


```ts
function topKFrequent(words: string[], k: number): string[] {
    const count = new Map()
    words.forEach(word => {
        count.set(word, (count.get(word) ?? 0) + 1)
    })
    const ans = []
    const maxLength = Math.max(...count.values())
    const bucket: string[][] = Array.from({ length: maxLength + 1 }, () => [])

    for (const [word, times] of count.entries()) {
        bucket[times].push(word)
    }
    for (let i = maxLength; i >= 0; i--) {
        if (bucket[i].length > 0) {
            bucket[i].sort()
            for (const word of bucket[i]) {
                ans.push(word)
                if (ans.length === k) {
                    break
                }
            }
        }
    }
    return ans
};
```
