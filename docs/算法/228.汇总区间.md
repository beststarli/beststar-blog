# [228.汇总区间](https://leetcode.cn/problems/summary-ranges/description/?envType=study-plan-v2&envId=top-interview-150)
给定一个 **无重复元素** 的 **有序** 整数数组 `nums` 。

区间 `[a,b]` 是从 `a` 到 `b`（包含）的所有整数的集合。

返回 恰好覆盖数组中所有数字 的 最小有序 区间范围列表 。也就是说，`nums` 的每个元素都恰好被某个区间范围所覆盖，并且不存在属于某个区间但不属于 `nums` 的数字 `x` 。

列表中的每个区间范围 `[a,b]` 应该按如下格式输出：
- `"a->b"` ，如果 `a != b`
- `"a"` ，如果 `a == b`

示例1：
- **输入**：nums = [0,1,2,4,5,7]
- **输出**：["0->2","4->5","7"]
- **解释**：
```txt
区间范围是：
[0,2] --> "0->2"
[4,5] --> "4->5"
[7,7] --> "7"
```

示例2：
- **输入**：nums = [0,2,3,4,6,8,9]
- **输出**：["0","2->4","6","8->9"]
- **解释**：
```txt
区间范围是：
[0,0] --> "0"
[2,4] --> "2->4"
[6,6] --> "6"
[8,9] --> "8->9"
```

## 解题思路
### 1.一次遍历
实际上就是看当前数字是否是前一个数字加1就能得到的，如果是就连续，如果不是就把前面连续的数字放入结果数组中，然后重新开始新的连续数字。这样做需要用一个临时数组来存储当前连续的数字，最后还需要判断一次临时数组是否为空，如果不为空就把它放入结果数组中。

- 时间复杂度：O(n)，其中 n 是数组 nums 的长度。我们只需要遍历一次数组。
- 空间复杂度：O(n)，其中 n 是数组 nums 的长度。我们需要一个临时数组来存储当前连续的数字，最坏情况下，所有数字都是连续的，我们需要存储所有数字。

```ts
function summaryRanges(nums: number[]): string[] {
    if (nums.length === 0) {
        return []
    }
    let temp = [nums[0]]
    const ans = []

    for (let i = 1; i < nums.length; i++) {
        if (nums[i] === nums[i - 1] + 1) {
            temp.push(nums[i])
        } else {
            if (temp.length > 1) {
                ans.push(temp[0] + '->' + temp[temp.length - 1])
            } else {
                ans.push(temp[0].toString())
            }
            temp = [nums[i]]
        }
    }

    if (temp.length !== 0) {
        if (temp.length > 1) {
            ans.push(temp[0] + '->' + temp[temp.length - 1])
        } else {
            ans.push(temp[0].toString())
        }
    }

    return ans
};
```

### 2.双指针
用双指针优化temp数组的使用，left指针指向当前连续数字的起点，right指针指向当前连续数字的终点，如果nums[right+1]不等于nums[right]+1就把left和right之间的数字放入结果数组中，然后重新开始新的连续数字。

- 时间复杂度：O(n)，其中 n 是数组 nums 的长度。我们只需要遍历一次数组。
- 空间复杂度：O(1)，我们只需要常数空间来存储指针，结果数组不计入空间复杂度。

```ts
function summaryRanges(nums: number[]): string[] {
    if (nums.length === 0) {
        return []
    }
    const ans = []
    let left = 0
    for (let right = 0; right < nums.length; right++) {
        if (right + 1 === nums.length || nums[right + 1] !== nums[right] + 1) {
            if (left === right) {
                ans.push(nums[left].toString())
            } else {
                ans.push(`${nums[left]}->${nums[right]}`)
            }
            left = right + 1
        }
    }
    return ans
};
```
