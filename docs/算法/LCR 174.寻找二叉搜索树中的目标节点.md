# [LCR 174.寻找二叉搜素树中的目标节点](https://leetcode.cn/problems/er-cha-sou-suo-shu-de-di-kda-jie-dian-lcof/description/)
某公司组织架构以二叉搜索树形式记录，节点值为处于该职位的员工编号。请返回第 `cnt` 大的员工编号。

示例1：
![LCR174-1](https://blog-1385521233.cos.ap-guangzhou.myqcloud.com/docs/algorithm/LCR174-1.png)
- **输入**：root = [7, 3, 9, 1, 5], cnt = 2
```txt
    7
   / \
  3   9
 / \
1   5
```
- **输出**：7

示例2：
![LCR174-2](https://blog-1385521233.cos.ap-guangzhou.myqcloud.com/docs/algorithm/LCR174-2.png)
- **输入**：root = [10, 5, 15, 2, 7, null, 20, 1, null, 6, 8], cnt = 4
```txt
      10
     / \
    5   15
   / \    \
  2   7    20
 /   / \ 
1   6   8
```
- **输出**：8

## 解题思路
### 1.中序遍历
注意到题目给定的二叉树通过中序遍历自然呈升序，题目要求返回的是第cnt**大**，所以应对遍历数组倒着计算位置返回结果。

- 时间复杂度：O(n)，其中 n 是二叉树的节点数。每个节点恰好被访问一次。
- 空间复杂度：O(n)，其中 n 是二叉树的节点数。

```ts
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function findTargetNode(root: TreeNode | null, cnt: number): number {
    const ans = []
    function dfs(node) {
        if (node === null) {
            return
        }
        dfs(node.left)
        ans.push(node.val)
        dfs(node.right)
    }
    dfs(root)
    return ans[ans.length - cnt]
};
```
