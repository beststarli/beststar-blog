# [106.从中序与后序遍历序列构造二叉树](https://leetcode.cn/problems/construct-binary-tree-from-inorder-and-postorder-traversal/description/)
给定两个整数数组 `inorder` 和 `postorder` ，其中 `inorder` 是二叉树的中序遍历， `postorder` 是同一棵树的后序遍历，请你构造并返回这颗 *二叉树* 。


示例1：
![106](https://blog-1385521233.cos.ap-guangzhou.myqcloud.com/docs/algorithm/106.jpg)
- **输入**：inorder = [9,3,15,20,7], postorder = [9,15,7,20,3]
- **输出**：[3,9,20,null,null,15,7]

示例2：
- **输入**：inorder = [-1], postorder = [-1]
- **输出**：[-1]

## 解题思路
### 1.DFS
与[105.从前序与中序遍历序列构造二叉树](/docs/算法/105.从前序与中序遍历序列构造二叉树.md)一样的思路，根据中序遍历与后序遍历的特点：
- 中序遍历：左子树 -> 根节点 -> 右子树
- 后序遍历：左子树 -> 右子树 -> 根节点

我们可以知道从后序遍历得到根节点的值，利用这个值通过indexOf方法在中序遍历中找到根节点的索引，这个索引向前就是左子树的节点，向后就是右子树的节点。接着，根据得到的左右子树在原中序遍历和后序遍历中的范围作为左右子树的中序遍历和后序遍历数组，递归构建左右子树即可。

- 时间复杂度：O(n)，其中 n 是二叉树的节点数。每个节点恰好被访问一次。
- 空间复杂度：O(n)，其中 n 是二叉树的节点数。

```ts
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function buildTree(inorder: number[], postorder: number[]): TreeNode | null {
    function dfs(inorderArr, postorderArr) {
        if (inorderArr.length === 0 && postorderArr.length === 0) {
            return null
        }
        const nodeVal = postorderArr[postorderArr.length - 1]
        const nodeInorder = inorderArr.indexOf(nodeVal)
        const leftLength = nodeInorder
        const rightLength = inorderArr.length - leftLength - 1

        const leftInorder = inorderArr.slice(0, nodeInorder)
        const leftPostorder = postorderArr.slice(0, leftLength)
        const rightInorder = inorderArr.slice(nodeInorder + 1)
        const rightPostorder = postorderArr.slice(leftLength, leftLength + rightLength)

        const newNode = new TreeNode(nodeVal)
        newNode.left = dfs(leftInorder, leftPostorder)
        newNode.right = dfs(rightInorder, rightPostorder)

        return newNode
    }
    return dfs(inorder, postorder)
};
```

### 2.哈希map优化
用哈希map来存储中序遍历的节点索引，避免每次都调用数组的`indexOf`方法来查找子树根节点的索引。加快检索速度。

- 时间复杂度：O(n)，其中 n 是二叉树的节点数。每个节点恰好被访问一次。
- 空间复杂度：O(n)，其中 n 是二叉树的节点数。

```js
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function buildTree(inorder: number[], postorder: number[]): TreeNode | null {
    const indexMap = new Map()
    inorder.forEach((value, index) => indexMap.set(value, index))

    function dfs(inorderLeft, postLeft, postRight) {
        if (postLeft === postRight) {
            return null
        }
        const leftSize = indexMap.get(postorder[postRight - 1]) - inorderLeft
        const left = dfs(inorderLeft, postLeft, postLeft + leftSize)
        const right = dfs(inorderLeft + leftSize + 1, postLeft + leftSize, postRight - 1)
        return new TreeNode(postorder[postRight - 1], left, right)
    }
    return dfs(0, 0, inorder.length)
};
```
