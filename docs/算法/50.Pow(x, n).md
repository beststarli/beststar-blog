# [50.Pow(x, n)](https://leetcode.cn/problems/powx-n/description/?envType=study-plan-v2&envId=top-interview-150)

实现 pow(x, n) ，即计算 `x` 的整数 `n` 次幂函数（即，x<sup>n</sup> ）。

示例1：
- **输入**：x = 2.00000, n = 10
- **输出**：1024.00000

示例2：
- **输入**：x = 2.10000, n = 3
- **输出**：9.26100

示例3：
- **输入**：x = 2.00000, n = -2
- **输出**：0.25000
- **解释**：2<sup>-2</sup> = 1/2<sup>2</sup> = 1/4 = 0.25

## 解题思路
### 1.递归
当n小于0时，看作是计算1/x的-n次幂。递归的终止条件是n为0时，返回1。然后将n除以2，递归计算x的n/2次幂，最后根据n的奇偶性返回结果。

- 时间复杂度：O(logn)，其中 n 是输入的数字。每次计算平方和的过程中，数字的位数会减少，因此循环的次数是对数级别的。
- 空间复杂度：O(logn)，其中 n 是输入的数字。递归调用栈的深度为 logn，因此空间复杂度为 O(logn)。

```ts
function myPow(x: number, n: number): number {
    function power(x, n) {
        if (n === 0) {
            return 1
        }
        let res = power(x, Math.floor(n / 2))
        res *= res
        if (n % 2) {
            res *= x
        }
        return res
    }

    if (n >= 0) {
        return power(x, n)
    }
    return 1 / power(x, -n)
};
```

### 2.快速幂
- 时间复杂度：O(logn)，其中 n 是输入的数字。每次计算平方和的过程中，数字的位数会减少，因此循环的次数是对数级别的。
- 空间复杂度：O(1)，使用常数级别的额外空间。

```ts
function myPow(x: number, n: number): number {
    function power(x, n) {
        let res = 1
        while (n) {
            if (n % 2) {
                res *= x
            }
            x *= x
            n = Math.floor(n / 2)
        }
        return res
    }  
    if (n >= 0) {
        return power(x, n)
    }
    return 1 / power(x, -n)
};
```
