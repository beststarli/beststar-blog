实现支持并发限制和先进先出（FIFO）的异步任务调度器。

```js
class TaskScheduler {  
  constructor(concurrency) { }  
  
  addTask(task) { }  
  
  runTasks() { }  
}
```

## 代码实现
### 基础版
```ts
class TaskScheduler {
    constructor(concurrency) {
        this.concurrency = concurrency;
        this.queue = []
        this.active = 0
        this.errors = []
        this._resolveAll = null
        this._rejectAll = null
    }

    addTask(task) {
        this.queue.push(task)
        return this   // 支持链式调用
    }

    runTasks() {
        return new Promise((resolve, reject) => {
            this._resolveAll = resolve
            this._rejectAll = reject
            this._drain()
        })
    }

    _drain() {
        while (this.active < this.concurrency && this.queue.length > 0) {
            const task = this.queue.shift()
            this.active++
            Promise.resolve()
                .then(() => task())
                .catch((err) => this.errors.push(err))
                .finally(() => {
                    this.active--
                    this._drain()
                    if (this.active === 0 && this.queue.length === 0) {
                        if (this.errors.length) {
                            this._rejectAll(this.errors)
                        } else {
                            this._resolveAll()
                        }
                    }
                })
        }
    }
}
```
使用示例：
```ts
const scheduler = new TaskScheduler(2);
scheduler.addTask(() => fetch(url1))
scheduler.addTask(() => fetch(url2))
scheduler.addTask(() => fetch(url3))

await scheduler.runTasks()
```

### 支持重试版
```ts
class TaskScheduler {
    constructor(concurrency, maxRetried = 2) {
        this.concurrency = concurrency;
        this.maxRetried = maxRetried
        this.queue = []
        this.active = 0
        this.errors = []
        this._resolveAll = null
        this._rejectAll = null
    }

    addTask(task) {
        this.queue.push({
            task,
            retries: 0
        })
        return this
    }

    runTasks() {
        return new Promise((resolve, reject) => {
            this._resolveAll = resolve
            this._rejectAll = reject
            this._drain()
        })
    }

    _drain() {
        while (this.active < this.concurrency && this.queue.length > 0) {
            const taskItem = this.queue.shift()
            this.active++
            Promise.resolve()
                .then(() => taskItem())
                .catch((err) => {
                    if (taskItem.retries < this.maxRetried) {
                        this.queue.unshift(taskItem)    // 保持FIFO
                    } else {
                        this.errors.push({
                            err,
                            task: taskItem.task
                        })
                    }
                })
                .finally(() => {
                    this.active--
                    this._drain()
                    if (this.active === 0 && this.queue.length === 0) {
                        if (this.errors.length) {
                            this._rejectAll(this.errors)
                        } else {
                            this._resolveAll()
                        }
                    }
                })
        }
    }
}
```

## 提问
### task返回什么类型
task是一个函数，返回一个Promise对象。

### 任务执行失败上面的功能可以执行吗？Promise如何处理错误但不阻塞队列？
仍可以执行，使用finally()方法释放占用并发数，并继续调用_drain()方法继续执行队列中的任务。

### catch()的时候能否将其加入队列重试
可以，任务队列存储的是任务对象，只需要每个传入的任务注册时为其对象再绑定一个重试次数属性，同时设置一个最大重试次数属性，防止无限重试。当任务对象的重试次数小于最大重试次数时，将其重新加入队列即可。为满足FIFO规则，使用unshift()方法将其加入队列头部。
