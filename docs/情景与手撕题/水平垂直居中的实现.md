水平垂直居中是前端开发中常见的布局需求，总结几种实现水平垂直居中的方法。

## 利用绝对定位
### 绝对定位与transform
利用绝对定位，先将元素的左上角通过top:50%和left:50%移动到页面的中心，再通过translate来调整元素的中心点到页面的中心。该方法需要考虑浏览器兼容问题。
```css
.parent {
  position: relative;
}

.child {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

### 绝对定位与margin自动
利用绝对定位，设置四个方向的值为0，并将margin设置为auto，由于高度固定，因此对应方向实现平分，可以实现水平和垂直方向上的居中。该方法适用于盒子有宽高的情况：
```css
.parent {
  position: relative;
}

.child {
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
  margin: auto;
  width: 100px;
  height: 100px;
}
```

### 绝对定位与负值margin
利用绝对定位，先将元素的左上角通过top:50%和left:50%移动到页面的中心，再通过margin负值来调整元素的中心点到页面的中心。该方法适用于盒子宽高已知的情况：
```css
.parent {
  position: relative;
}

.child {
  position: absolute;
  top: 50%;
  left: 50%;
  margin-left: -50px; /* child宽度的一半 */
  margin-top: -50px; /* child高度的一半 */
}
```

## 利用flex布局
使用flex布局，通过align-items:center和justify-content:center设置容器的垂直和水平方向上为居中对齐，然后它的子元素也可以实现垂直水平居中。该方法要考虑浏览器兼容性问题，适用于移动端较多：
```css
.parent {
  display: flex;
  align-items: center; /* 垂直居中 */
  justify-content: center; /* 水平居中 */
}
```

## 利用table布局
设置父元素为 display:table-cell ，子元素设置vertical和 text-align 可以让所有的行内display: inline-block 。利用块级元素水平垂直居中。
```html
<style>
.father {
  display: table-cell;
  width: 200px;
  height: 200px;
  background: skyblue;
  vertical-align: middle;
  text-align: center;
}
.son {
  display: inline-block;
  width: 100px;
  height: 100px;
  background: red;
}
</style>
<div class="father">
  <div class="son"></div>
</div>
```

## 利用grid布局
```html
<style>
.father {
  display: grid;
  align-items:center;
  justify-content: center;
  width: 200px;
  height: 200px;
  background: skyblue;
}
.son {
  width: 10px;
  height: 10px;
  border: 1px solid red
}
</style>
<div class="father">
  <div class="son"></div>
</div>
```
与flex布局一样，直接使用align-items:center和justify-content: center设置容器的垂直和水平方向上为居中对齐，然后它的子元素也可以实现垂直水平居中。

## 总结
### 内联元素居中布局
#### 水平居中
- 行内元素：text-align: center
- flex布局：设置父元素为display:flex，justify-content:center
#### 垂直剧中
- 单行文本父元素确认高度：height === line-height
- 多行文本父元素确认高度：display: table-cell, vertical-align: middle

### 块级元素居中布局
#### 水平居中
- 确定高度：margin: 0 auto
- 绝对定位：left: 50%, margin: -50%自身宽度
- 绝对定位：left: 50%, transfrom: translateX(-50%)

#### 垂直居中
- position: absolute：设置left、top、margin-left、margin-top(确定高度)
- display: table-cell
- transform: translate(x, y)
