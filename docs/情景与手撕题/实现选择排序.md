选择排序的思路就是，外层循环对数组的每个元素进行遍历，取当前遍历元素为最小值，内层循环以当前元素的下一个为起点继续向后遍历寻找更小的值，不断更新最小值的下标，直到内层循环结束，将最小值与当前遍历元素交换位置。重复这个过程直到外层循环结束。

- 时间复杂度：O(n^2)，其中 n 是数组的长度。最坏情况下，每次插入都需要将前面所有的元素向后移动一位。
- 空间复杂度：O(1)，我们只需要常数级别的额外空间。

## 代码实现
```js
function selectionSort(nums) {
  // TODO
  for (let i = 0; i < nums.length; i++) {
    let k = i
    for (let j = i + 1; j < nums.length; j++) {
      if (nums[j] < nums[k]) {
        k = j
      }
    }
    ;[nums[i], nums[k]] = [nums[k], nums[i]]
  }
  return nums
}
```
