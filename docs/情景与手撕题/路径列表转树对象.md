给定若干以 / 分隔的路径字符串，合并为嵌套对象；叶节点对应空对象 {}。
## 代码实现
```js
function pathsToTree(segmentsList) {
  const root = {}
  for (const path of segmentsList) {
    const parts = path.split('/')
    let tempObject = root
    for (const part of parts) {
      if (!(part in tempObject)) {
        tempObject[part] = {}
      }
      tempObject = tempObject[part]
    }
  }
  return root
}
```

输出结果1:
- **输入**：
```txt
[
  "a/b/c",
  "a/b/d",
  "a/e",
  "f/g",
  "h"
]
```
- **输出**：
```txt
{
  "a": {
    "b": {
      "c": {},
      "d": {}
    },
    "e": {}
  },
  "f": {
    "g": {}
  },
  "h": {}
}
```

输出结果2:


- **输出**：
