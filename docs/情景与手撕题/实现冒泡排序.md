通过两次循环相邻元素两两交换，完成冒泡。外层一趟循环会对当前数组内可冒泡的元素交换一次，直到遍历结束则交换完成

- 时间复杂度：O(n^2)，其中 n 是数组的长度。最坏情况下，每次插入都需要将前面所有的元素向后移动一位。
- 空间复杂度：O(1)，我们只需要常数级别的额外空间。

## 代码实现
### 正向遍历
```js
function bubbleSort(nums) {
  const a = nums.slice();
  for (let i = 0; i < a.length - 1; i++) {
    for (let j = 0; j < a.length - 1 - i; j++) {
      if (a[j] > a[j + 1]) [a[j], a[j + 1]] = [a[j + 1], a[j]];
    }
  }
  return a;
}
```
### 反向遍历
更好理解一些
```js
function bubbleSort(nums) {
  for (let i = nums.length - 1; i > 0; i--) {
    for (let j = 0; j < i; j++) {
      if (nums[j] > nums[j + 1]) {
        [nums[j], nums[j + 1]] = [nums[j + 1], nums[j]]
      }
    }
  }
  return nums 
}
```
