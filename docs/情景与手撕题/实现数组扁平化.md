## 递归实现
普通的递归思路很好理解，通过循环递归的方式一项一项地遍历，如果每一项还是一个数组，那么就继续往下遍历，利用递归程序的方法实现数组的每一项的连接：
```js
const arr = [1, 2, 3, [[4, 5], 6], 7, 8, 9]
function flatten(arr) {
  let result = []
  for (let i = 0; i < arr.length; i++) {
    if (Array.isArray(arr[i])) {
      result = result.concat(flatten(arr[i]))
    } else {
      result.push(arr[i])
    }
  }
  return result
}

flatten(arr)  // [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

## reduce方法实现
从递归可以看出就是对数组的每一项进行处理，那么其实可以用到reduce来实现数组的拼接，从而简化递归方法的代码：
```js
const arr = [1, 2, 3, [[4, 5], 6], 7, 8, 9]
function flatten(arr) {
  return arr.reduce((prev, next) => {
    return prev.concat(Array.isArray(next) ? flatten(next) : next)
  }, [])
}
console.log(flatten(arr))  // [1, 2, 3, 4, 5, 6, 7, 8, 9]
```


## 扩展运算符实现
这个方法采用了扩展运算符和some方法，两者共同使用，达到数组扁平化的目的：
```js
const arr = [1, 2, 3, [[4, 5], 6], 7, 8, 9]
function flatten(arr) {
  while (arr.some(item => Array.isArray(item))) {
    arr = [].concat(...arr)
  }
  return arr
}
console.log(flatten(arr))  // [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

## 字符串处理
可以通过split和toString方法来共同实现数组扁平化，由于数组会默认带一个toString方法，所以可以直接把数组转换成逗号分隔的字符串，然后再用split方法把字符串重新转换为数组：
```js
const arr = [1, 2, 3, [[4, 5], 6], 7, 8, 9]
function flatten(arr) {
  return arr.toString().split(',')
}
console.log(flatten(arr))  // ['1', '2', '3', '4', '5', '6', '7', '8', '9']
```

## ES6 flat方法实现
可以直接调用ES6的flat方法来实现数组扁平化，flat方法的语法是：
```js
arr.flat([depth])
```
其中depth是flat的参数，depth是可以传递数组的展开深度（默认不填写，数值为1），即展开一层数组，如果层数不确定，参数可以传入Infinity，代表无论多少层都展开：
```js
const arr = [1, 2, 3, [[4, 5], 6], 7, 8, 9]
function flatten(arr) {
  return arr.flat(Infinity)
}
console.log(flatten(arr))  // [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

## 正则表达式和JSON方法
先采用JSON.stringify将数组转换为字符串，然后通过正则表达式过滤掉字符串中的数组括号，再利用JSON.parse将字符串转换为数组：
```js
const arr = [1, 2, 3, [[4, 5], 6], 7, 8, 9]
function flatten(arr) {
  let str = JSON.stringify(arr)
  str = str.replace(/\[|\]/g, '')
  str = '[' + str + ']'
  return JSON.parse(str)
}
console.log(flatten(arr))  // [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

## 实战：将数组扁平到指定深度
要求：（并解释思路）
1. 不能使用原生的`Array.prototype.flat`方法
2. 必须正确处理各种数据类型（数字、字符串、对象、null、undefined等）
3. 必须正确处理稀疏数组 [,,,,]
4. 必须支持Infinity作为深度参数
5. 必须正确处理循环引用（加分项）

```js
const seen = new WeakSet()

// depth设置默认值1，处理默认深度
function flat(arr, depth = 1) {
	// 判断传入参数是否是数组，不是则包装为数组返回
	if (Array.isArray(arr)) {
		return [arr]
	}

	// 防止循环引用
	if (seen.has(arr)) {
		return [arr]
	}
	seen.add(arr)

	const result = []
	for (let i = 0; i < arr.length; i++) {
		// 处理稀疏数组
		if (!(i in arr)) {
			result.length++
			continue
		}

		const value = arr[i]
		// 向下递归，判断当前遍历值是否仍是数组且可用深度大于0
		// 是则更新递归深度，得到当前遍历值数组的扁平数组并其展开的值传入结果数组
		// 否则直接将遍历值推入结果
		if (Array.isArray(value) && depth > 0) {
			// 处理深度为Infinity的情况，Infinity - 1仍然是Infinity
			const newDepth = (depth === Infinity) ? Infinity : depth - 1
			// 向下递归，得到当前遍历值数组的扁平数组
			const sonFlattenArr = flat(value, newDepth)
			result.push(...sonFlattenArr)
		} else {
			result.push(value)
		}
	}
	return result
}
