观察者模式是一种行为型设计模式，定义了一种一对多的依赖关系：当一个对象（主题/被观察者）的状态发生变化时，所有依赖它的对象（观察者）都会自动收到通知并更新。

## 代码实现
建立一个主题类（Subject）和一个观察者类（Observer），主题类维护一个观察者列表，当状态发生变化时，通知所有观察者。

实现 Subject 与 Observer：Subject 提供 addObserver、removeObserver、notify；Observer 构造时接收回调，在 update(data) 中调用。notify 须通知当前仍注册的所有观察者。

其实理解下来很简单，Subject是一个观察者数组，其中的addObserver方法就是向这个数组中添加新的观察者，removeObserver方法就是从数组中找到要移除的数组下标，调用splice()方法移除，notify方法就是遍历整个数组对其中的观察者都调用他们的回调函数，回调函数的参数就是notify接收的参数。

Observer就是一个观察者类，构造函数接收一个回调函数，update方法就是调用这个回调函数。

```js
class Subject {
  // TODO：维护观察者列表
  constructor() {
    this.observers = []
  }

  addObserver(observer) {
    this.observers.push(observer)
  }

  removeObserver(observer) {
    const observerIndex = this.observers.indexOf(observer)
    if (observerIndex !== -1) {
      this.observers.splice(observerIndex, 1)
    }
  }

  notify(data) {
    for (const observer of this.observers) {
      observer.update(data)
    }
  }
}

class Observer {
  // TODO：保存回调并在 update 中触发
  constructor(fn) {
    this.fn = fn
  }

  update(data) {
    this.fn(data)
  }
}
```
使用示例：
```js
function summarizeObserverTrace(scenario) {
  if (scenario === 'unregister') {
    const hub = new Subject();
    const log = [];
    const first = new Observer((payload) => log.push(`a:${payload}`));
    const second = new Observer((payload) => log.push(`b:${payload}`));
    hub.addObserver(first);
    hub.addObserver(second);
    hub.notify(1);
    hub.removeObserver(first);
    hub.notify(2);
    return log.join('|');
  }
  if (scenario === 'fanOut') {
    const hub = new Subject();
    const buf = [];
    hub.addObserver(new Observer((value) => buf.push(value * 10)));
    hub.addObserver(new Observer((value) => buf.push(value + 5)));
    hub.notify(3);
    return buf.join(',');
  }
}
```
输出结果：
```txt
'unregister': 'a:1|b:1|b:2',
'fanOut': '30,8'
```
