将嵌套对象拍平为一层，键名用 `.` 连接。注意：值为 null 仍保留；数组按下标展开为路径段。
## 代码实现
```js
function flattenObj(nested) {
  const flatten = {}
  function dfs(value, prefix) {
    if (value !== null && typeof value === 'object' && !Array.isArray(value)) {
      for (const key of Object.keys(value)) {
        prefix = prefix === '' ? key : `${prefix}.${key}`
        dfs(value[key], prefix)
      }
    } else if (Array.isArray(value)) {
      value.forEach((item, index) => {
        const path = `${prefix}.${index}`
        if (item !== null && typeof item === 'object' && !Array.isArray(item)) {
          dfs(item, path)
        } else {
          flatten[path] = item
        }
      })
    }
  }
  dfs(nested, '')
  return flatten
}
```

输出结果1:
- **输入**：
```txt
{"a":{"b":{"c":1}},"d":2,"e":{"f":{"g":"hello"}}}
```
- **输出**：
```txt
{ 
  "a.b.c":1,
  "d":2,
  "e.f.g":"hello"
}
```

输出结果2:
- **输入**：
```txt
{"a":[1,2,{"b":3}],"c":{"d":null}}
```
- **输出**：
```txt
{"a.0":1,"a.1":2,"a.2.b":3,"c.d":null}
```

输出结果3:
- **输入**：
```txt
{"x":1,"y":{"z":2}}
```
- **输出**：
```txt
{"x":1,"y.z":2}
```

输出结果4:
- **输入**：
```txt
{}
```
- **输出**：
```txt
{}
```
