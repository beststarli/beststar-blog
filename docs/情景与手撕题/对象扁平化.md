将嵌套对象拍平为一层，键名用 `.` 连接。注意：值为 null 仍保留；数组按下标展开为路径段。
## 代码实现
```js
function flattenObj(nested) {
  // TODO：DFS 遍历；null 作为叶子直接写入
    const flatten = {}
    function dfs(obj, prefix) {
      if (obj !== null && typeof obj === 'object') {
        if (Array.isArray(obj) === false) {
          for (const [key, value] of Object.entries(obj)) {
            const path = prefix === '' ? key : `${prefix}.${key}`
            dfs(value, path)
          }
        } else {
          obj.forEach((value, index) => {
            const path = prefix === '' ? String(index) : `${prefix}.${index}`  // 修前导点
            dfs(value, path)
          })
        }
      } else {
        flatten[prefix] = obj
      }
    }
    dfs(nested, '')
    return flatten
}
```

输出结果1:
- **输入**：
```txt
{"a":{"b":{"c":1}},"d":2,"e":{"f":{"g":"hello"}}}
```
- **输出**：
```txt
{ 
  "a.b.c":1,
  "d":2,
  "e.f.g":"hello"
}
```

输出结果2:
- **输入**：
```txt
{"a":[1,2,{"b":3}],"c":{"d":null}}
```
- **输出**：
```txt
{"a.0":1,"a.1":2,"a.2.b":3,"c.d":null}
```

输出结果3:
- **输入**：
```txt
{"x":1,"y":{"z":2}}
```
- **输出**：
```txt
{"x":1,"y.z":2}
```

输出结果4:
- **输入**：
```txt
{}
```
- **输出**：
```txt
{}
```
