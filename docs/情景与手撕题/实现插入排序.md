插入排序的思路就是，先用一层循环对数组进行遍历，假设第一个数即 `i = 0` 已经处于排好序的状态，从 `i = 1` 开始遍历，取出当前的数 `base = nums[i]`，然后用一个 `j` 指针从 `i - 1` 开始向前遍历，直到找到第一个比 `base` 小的数 `nums[j]`，将 `nums[j]` 后移一位 `nums[j + 1] = nums[j]`，直到 `j < 0` 或者 `nums[j] <= base` 时，将 `base` 插入到 `nums[j + 1]` 的位置。

- 时间复杂度：O(n^2)，其中 n 是数组的长度。最坏情况下，每次插入都需要将前面所有的元素向后移动一位。
- 空间复杂度：O(1)，我们只需要常数级别的额外空间。

## 代码实现
```js
function insertionSort(nums) {
  // TODO
  for (let i = 1; i < nums.length; i++) {
    const base = nums[i]
    let j = i - 1
    while (j >= 0 && nums[j] > base) {
      nums[j + 1] = nums[j]
      j--
    }
    nums[j + 1] = base
  }
  return nums
}
```
